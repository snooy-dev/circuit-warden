# Feature Specification: 첫 레벨 플레이 결함 개선

**Date** 2026-11-26 | **Status** Ready

## User Scenarios & Testing (mandatory)

### User Story 1 - 첫 레벨을 마치거나 다시 시작한다 (Priority: P1)

전원 구역을 플레이하는 사람이 전체화면에서도 워든이 쓰러졌거나 출력에 도달했음을 읽고 R로 다시 시작할 수 있다.

### User Story 2 - 보고 누른 조작이 바로 적용된다 (Priority: P1)

컷신 건너뛰기 직후의 첫 이동이 적용되고, 전하는 이동 가능할 때 밝아진다.

## Requirements (mandatory)

- **FR-001** 전원 구역 출력을 완료하거나 워든이 쓰러지면 플레이 화면에 상태와 R 재시작 키를 표시한다. R 이후에는 현재 위치의 안내 상태로 돌아간다.
- **FR-002** 기존 점프 통합 검사는 현재 공중 공격 재생률과 점프·착지 규칙으로 검증한다.
- **FR-003** Escape나 Skip 입력을 처리한 시점에 컷신을 닫고 이후 이벤트를 일반 조작으로 전달한다.
- **FR-004** 전하의 활성 표시에 클릭과 같은 이동 가능 판정을 사용한다. 워든의 도착 몸통이 카메라 하단을 벗어나는 경우도 차단한다.
- **FR-005** 양쪽 진행 경로의 검사는 실시간 입력에서 안정적으로 도달 가능한 상부 발판 출발점을 사용한다.
- **FR-006** 우클릭은 현재 순간이동 기준점에 겹친 전하를 건너뛰고 실제로 이동할 수 있는 가장 가까운 전하를 고른다.
- **FR-007** 보스 처치 후 부하 시험실과 출력실에서 최종 출력 단자 방향을 알린다. 출력 완료와 상호작용 안내를 우선한다.

## Success Criteria (mandatory)

- **SC-001** 워든 사망과 출력 완료 후 상태 문구를 확인하고 R로 초기화한다. 출력은 릴레이 복구·보스 처치 후에만 가능하다.
- **SC-002** 기존 점프 검사의 지상·공중·착지 전이와 새 발판 유예 검사가 함께 통과한다.
- **SC-003** 두 종류의 건너뛰기와 바로 이어진 D 입력을 확인하고, 같은 방 격벽과 카메라 하단이 전하 표시·선택에 같은 영향을 주는지 확인한다.
