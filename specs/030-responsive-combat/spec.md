# Feature Specification: 착지·검격·피격 조작 반응

**Date** 2026-11-26 | **Status** Ready

## User Scenarios & Testing (mandatory)

### User Story 1 - 착지 후 곧바로 다음 행동을 한다 (Priority: P1)

일반 착지에서 방향키를 누르면 바로 달리고, 공격이나 대시를 누르면 착지 모션에서 해당 행동으로 이어진다. 중립 착지에서 전용 모션이 보이고, 가변 점프와 발판 끝 입력 유예가 작동한다.

### User Story 2 - 검격과 피격을 구분하고 반격한다 (Priority: P1)

검 입력 후 베기와 타격 판정이 조금 빨리 나오고, 적이나 활선에 맞으면 구분되는 피격 섬광을 본다. 피격 뒤 새로 누른 J나 Shift가 손실되지 않는다.

## Requirements (mandatory)

- **FR-001** 지형에 착지해 일반 조작을 할 수 있는 경우 A/D·공격·대시가 착지 모션을 끊을 수 있다. 대시 진행 중 착지 및 Space 선입력, 점프 궤적·이동 기본 속도는 기존 규칙을 따른다.
- **FR-002** 지상·공중 검격 모션, 베기 효과와 타격 판정을 함께 80% 재생한다. 재생률은 플레이 평가를 위한 시험값이다.
- **FR-003** 실제 피격 후 새 공격·대시 입력은 150ms 동안 보관한다. 반동 잠금·공중 대시 사용 제한은 적용한다.
- **FR-004** 살아남은 워든이 실제 피해를 받으면 기존 섬광을 1.3배로 표시한다. 전원 구역 활선 피해도 같은 효과를 사용한다.

## Success Criteria (mandatory)

- **SC-001** 착지에서 이동·공격·대시와 재점프를 확인하고, 양쪽 분기에서 기존 점프 도달과 전하 연계를 확인한다.
- **SC-002** 검격 타격 시각, 보스·일반 적 전투, 피격 보호와 후속 입력·활선 효과를 자동 검사와 SDL 실행에서 확인한다.
