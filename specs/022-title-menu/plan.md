# Implementation Plan: 게임 타이틀 메뉴

**Spec**: [타이틀 메뉴](spec.md)

## Technical Context

Python + Pico2D의 Engine, Canvas, Renderer를 사용한다. Canvas 순서와 논리 좌표를 입력과 렌더링이 함께 사용하고 버튼 콜백으로 장면의 동작을 호출한다. 텍스트는 지정한 폰트에서 필요한 문자열만 텍스처로 변환하고 장면에서 해제한다.

## Implementation

1. UI 입력과 텍스트·버튼 위젯을 구현하고 타이틀 장면에서 재사용한다.
2. 기본 진입점을 타이틀로 변경한다. 기존 연습장 플래그와 화면 전환 API를 유지한다.
3. 실제 SDL 창에서 시작·종료·설정 전환과 크기 변경 이후 입력을 확인한다. 드래그 취소와 상태 격리는 집중 자동 검사로 확인한다.
4. 관련 docs와 verification을 동기화한다.
5. 시각 보정은 타이틀 장면에 둔 메뉴 스타일과 설정값 열에 적용한다. 기존 전원 구역 원경과 배포용 글꼴을 사용하고 기본·축소·전체화면의 합성 화면을 확인한다.

## Constitution Check

사용자 요청을 진행 근거로 사용한다. 설정 항목과 키 배치는 기존 화면 기능을 연결하기 위한 기술적 선택이다. 기존 Canvas 렌더 계약과 Pico2D 의존성을 유지한다.
