# Data Model: 기본 적 전투

| 대상 | 상태·제약 |
|---|---|
| 워든 | 초기 체력 5. 피해 1마다 감소하며 하한은 0. 피격 보호 0.75초. 체력 0에서 일반 입력과 적 행동 정지. |
| 워든 검 공격 | 공격 ID당 최대 1회 명중. 활성 구간 [0.10, 0.20)초, 방향 고정, 전방 85와 바닥 기준 높이 8~70. |
| 금속 먼지 덩어리 | 초기 체력 3, 피해 1, 피격 표시 0.18초. 대기·접근·예고·돌진·회복. 체력 0에서 전투와 표시에서 제거. |
| 적 돌진 | 예고 시 방향 고정. 돌진당 최대 1회 피해. |
| 기본 전투 | 한 마리 배치. R로 체력·위치·행동·피격 보호와 공격 중복 판정 기록 초기화. |
