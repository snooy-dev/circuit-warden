# Implementation Plan: 전투 조작과 플랫폼 테스트 맵 재구현

**Date**: 2026-11-23 | **Spec**: [명세](spec.md) | **Status**: Ready

## Summary

워든의 공격 재생과 수평 이동을 함께 진행시킨다. 입력을 놓으면 플레이어가 시작한 점프의 양의 속도만 줄인다. 기존 Level의 블로킹과 오버랩을 이용해 플랫폼·벽·이동하는 검을 구현하고 LevelScene의 투영 중심을 움직인다.

## Technical Context

- Python/Pico2D와 기존 애니메이션, 입력 버퍼, 월드 좌표, AABB 충돌을 사용한다.
- Space를 놓으면 남은 상승을 줄인다. 세부 값은 아래 후속 조정을 따른다. 지상 공격의 자동 전진은 제거한다. 카메라 시간 상수와 맵 치수는 테스트 튜닝 값이다.
- 기존 워든 몸체·공격 자세와 전하·대시·피격의 입력 및 취소 계약을 보존한다. 분리 가능한 효과는 몸체 대신 효과 픽셀만 수정한다.

## Follow-up: 이동과 점프 반응 조정

할로우 나이트의 방향 유지 달리기와 버튼 유지 점프를 참고한다. 워든의 시험값으로 기본 이동을 240 월드 단위/초로 높이고, 시작 클립 12프레임을 30ms로 압축한다. 상승 중 Space를 떼면 그 순간의 상승 속도에 0.65를 한 번 곱한다. 이륙 전 해제에도 같은 비율을 적용한다. 착지의 웅크림 연결은 기존 자세에 맞추고, 최대 점프 높이·중력·대시·순간이동은 기존 값을 쓴다. `game/character.py`, `assets/warden/animations.json`을 수정하고 관련 표적 검사와 SDL 훈련장 검사로 확인한다. 기본 게임플레이·기술 구조·진행 상태를 갱신한다.

## Follow-up: 착지 시점의 재점프

[Celeste 개발자 설명](https://www.mattmakesgames.com/articles/celeste_and_forgiveness/index.html)의 접지 즉시 재점프를 참고한다. 워든은 공중에서 새 Space 입력을 120ms 보관한다. 지상에서 잠긴 행동에 대한 점프와 공격·대시는 기존 100ms를 사용한다. 일반 점프와 재점프가 이륙 처리를 공유하며, 재점프는 착지와 시작 모션을 건너뛴다. 입력을 소비한 뒤 남은 갱신 시간은 상승에 반영한다. 대시·피격 잠금과 마지막 입력 우선순위를 유지한다. 평지·발판, 만료 경계, 짧은 탭, 긴 갱신, 공중 공격 착지와 SDL 입력을 점검하고 기본 게임플레이·기술 구조·진행 상태를 갱신한다.

## Follow-up: 지상 공격 접지와 베기

지상 공격 동안 이동 키로 인한 수평 이동을 멈춘다. 이동 입력이 있으면 240ms부터 회복을 달리기로 연결하고, 미입력 시 준비·타격·회복 340ms를 재생한다. 공격 시작과 피해 유효 구간, 공격 방향, 공중 공격의 조향은 기존 규칙을 사용한다. 긴 갱신은 달리기로 전환되는 시각에서 나눠 남은 시간만 수평 이동에 반영한다. 기존 원화로 새 공격 영상을 생성해 접지·검 궤적·디자인을 확인하고, 통과한 자세를 같은 피벗·크기로 쓴다. 효과는 검이 전방을 통과하는 핵심 구간에 맞춰 베이크한다. 검증은 좌우 입력·회복 전환·타격과 벽 접촉·SDL 캡처를 포함한다. 기준 문서와 게임 시트 출처를 갱신한다.

## Follow-up: 분기 방전 초승달 적용

사용자가 적용을 지시한 Pixelfx 분기 방전 초승달의 224×208·6셀을 기존 몸체 위에 발 피벗으로 정렬해 `assets/warden/attack.png`에 베이크한다. 현재 시트의 256×224·6열·17프레임 및 (128,136) 피벗과 기존 재생 코드를 사용한다. 효과 전후 셀을 바이트 단위로 대조하고 기본 레벨의 실제 SDL 창에서 지상 공격만 좌우로 확인한다. 아트 기준, 기본 게임플레이, 진행 상태, 자산 출처와 검증 기록을 맞춘다.
