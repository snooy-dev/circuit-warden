# Feature Specification: 워든 측면 명암 복원

**Created**: 2026-11-10
**Status**: Ready
**Input**: 해당 복원작업을 진행한다.
**Design approval**: 색조·입체감 불일치 원인과 복원 방향을 사용자가 확인했다. 세부 구현 수치는 기술적 가정이다.
**Implementation authorization**: 원화에 맞춘 측면 기준 이미지 복원과 기존 동작 재출력. 게임 통합·최종 사용 승인은 제외한다.

## Intent & Scope

측면 기준 이미지의 넓은 시안·노란 강조·보라 그림자를 원화의 청색 중간 명암과 곡면 표현으로 복원한다. 기본 복원 단계에서는 원형을 보존한다. 이후 사용자 지시에 따라 둥근 발 형태를 복원하고 몸을 오른쪽으로 약20도, 이어 몸통은10도 추가·머리는10도 반대로 조정한다. 각도는 시각적 목표이며 실측값이 아니다. 걷기/Run/공격의 속도·발 궤적·관성은 유지한다. 원화와 idle은 변경하지 않는다. 공격은 현재 v6의 색만 검토용으로 갱신하며 새 동작과 검 출현 VFX는 제외한다.

## User Scenarios & Testing (mandatory)

### User Story 1 - 원화와 일관된 측면 색감 (Priority: P1)
**Why this priority**: 동작 전환 때 다른 캐릭터처럼 보이는 색조와 평평한 표현을 줄인다.
**Independent Test**: 원화·idle·기존 측면·복원 측면을 같은 배경과 표시 크기에서 비교한다.
**Acceptance Scenarios**:
1. **Given** 파생 측면 그림, **When** 복원, **Then** 청색 중간 명암이 얼굴·귀·몸통의 곡면을 설명하고 노랑·보라 색조가 제거된다.
2. **Given** 기존 동작, **When** 복원 결과를 적용, **Then** 타이밍·실루엣·전류 진행·부속 관성과 검의 동작은 유지된다.

### Edge Cases

이미지 편집으로 눈·윤곽·전류선 위치가 변할 수 있다. 원본 구조에 정합하고 원래 알파·눈·전류를 보존하며 미리보기에서 경계·이탈을 검사한다. 자동 통계만으로 입체감 개선을 판정하지 않는다.

## Requirements (mandatory)
### Functional Requirements
- **FR-001**: 원화의 청색·시안 명암 관계와 곡면 표현을 측면 이미지에서 복원한다.
- **FR-002**: 원화의 짧은 사지와 둥근 발·꼬리 및 머리/귀 비율을 유지하며 요청한 몸·머리 방향을 적용한다.
- **FR-003**: 걷기 24프레임/1초·Run 16프레임/480ms·공격 24프레임/720ms와 전류·관성을 유지한다.
- **FR-004**: 기존 잠정 승인 PNG 128개와 원화·측면 소스를 변경하지 않고 별도 검토본을 만든다.
- **FR-005**: 고해상도 소스와 실제 hibit 표시 크기를 모두 비교하고 색·알파·프레임·출처 검증을 기록한다.
### Constraints
Python + Pico2D 게임 코드는 변경하지 않는다. 16색 hibit·몸 높이80px·원래 캔버스/기준점을 유지한다. 새 모델은 정지 이미지 명암 편집에만 사용하고 움직임은 기존 코드다.

## Success Criteria (mandatory)
- **SC-001**: 색감만 복원한 단계에서는 알파 동일성을 확인한다. 발·방향 수정 단계는 의도된 윤곽 변경을 별도로 검토하며 기존 승인128PNG 해시는 유지한다.
- **SC-002**: 색감만 복원한 프레임의 알파·타이밍·물리/전류는 기존과 일치한다. 방향·발 수정 뒤에는 새 부위 위치에 맞게 경로를 조정하되 속도·발 궤적·관성 기준을 유지하고 부위 이탈·가랑이 구멍을 검사한다.
- **SC-003**: 원화·idle과 비교해 중간 청색 명암과 곡면을 시각 검토할 수 있는 비교 자료를 제공한다.
- **SC-DOC**: docs·명세·계획·검증이 실제 결과와 일치한다.

## Assumptions & Open Decisions

새 결과는 검토 후보이며 잠정 승인본을 자동 대체하지 않는다. 각도별 픽셀 분포가 달라 idle 통계를 강제로 동일하게 맞추지 않는다. 형상 보존을 위해 편집된 RGB를 기존 좌표·알파에 정합할 수 있다.

최신 사용자 요청은 비율 검사에 근거한 귀·팔 축소다. 정지 수정본과 [비율 검증](proportion-verification.md)을 준비했으며 최신 자세의 동작 적용은 남는다.
