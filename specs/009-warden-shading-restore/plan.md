# Implementation Plan: 워든 측면 명암 복원

**Date**: 2026-11-10 | **Spec**: [spec.md](spec.md) | **Status**: Ready

## Summary
내장 이미지 편집 도구로 기존 측면 그림의 명암만 원화에 맞춘다. 편집 결과를 원본 좌표에 정합하고 원래 알파·눈·전류 경로를 보존해 기존 코드 동작에 주입한다. 비교 후 별도 검토본으로 제공한다.

## Technical Context
- 도구 Python/Pillow/NumPy/SciPy와 기존 제작 함수 재사용. 게임 의존성 변경 없음.
- 정지 그림: host-image_gen 편집. 동작: 기존 코드. 새 영상 생성 없음.
- 1024×1024 원본 좌표·원본 알파, 80px 몸 높이·16색 hibit·기존 캔버스.
- 검증: 원본 해시, 픽셀 알파·타이밍·물리·전류 일치, 소스/1배/확대 시각 비교.

## Constitution Check

- [x] 기존 명암 검사와 아트 기준을 읽었다.
- [x] docs·검증·기존파일 보존을 계획했다.
- [x] 새 게임 기능·엔진·의존성은 없다.

## Decisions & Alternatives
전체 밝기 감소와 히스토그램 강제 일치는 곡면 명암을 되살리지 못하므로 채택하지 않는다. 원본 실루엣 보존을 위해 RGB 정합/알파 고정을 적용할 수 있으며 눈과 전류 원래 위치를 보존한다. 편집 결과가 다른 포즈라면 채택하지 않고 수정한다. 걷기·Run 및 같은 몸체를 쓰는 공격을 동일 소스로 재출력한다.

## Project Structure & Interfaces
art/warden/shading-restore/에 원본 해시·프롬프트·편집본·정합본·동작 검토본을 둔다. 기존 build_walk.py, build_sprint_v3.py, build_attack.py를 재사용하며 원본 제작코드는 수정하지 않는다. 재현용 최소 어댑터와 검사 코드는 specs/009-warden-shading-restore/에 보존한다. 외부 인터페이스가 없어 contracts는 불필요하다.

## Verification & Risks
이미지 편집이 형태를 미세하게 바꿀 수 있으므로 기존 실루엣을 고정하며 등록 오차·눈 경계·천 겹침을 관찰한다. 색 통계는 참고이며 곡면 회복의 자동 합격 기준으로 사용하지 않는다. 기존 승인128PNG와 소스 해시 보존, 프레임 알파/물리/전류·타이밍 비교를 통과해야 한다. 게임 적용·게임 테스트는 범위 밖이다.

## 최신 발·방향 수정과 검사

색감만 복원한 review-v1을 보존한다. 추가 발/몸/머리 방향 지시로 전체 알파 동일성 조건은 이 단계에만 적용한다. split-turn-v1의 귀·팔 과대를 수정한 proportion-fix-v1을 준비했다. 몸통을 일괄 축소하지 않고 가까운 귀와 팔의 상대 크기를 맞춰 정지 검토를 통과했다. 발 하단은 형태를 유지해 이동하고 짧은 상단 연결부에서만 변형하는 방식으로 리그 개선을 검토한다. 타이밍과 보폭은 유지한다. 현재 최신 자세의 리그 적용은 진행하지 않았다.
