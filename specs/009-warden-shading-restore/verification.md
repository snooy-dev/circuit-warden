# Verification: 명암 복원과 비율 검사

현재 유효한 최신 판정은 [비율 검증](proportion-verification.md)이다. 제작 전체는 미완료다.

- `build_review.py`: 종료0. 색감 전용 review-v1 걷기24/Run16/공격24프레임 출력, 기존 프레임 알파·전류 레이어·16색·타이밍 일치, 기존 승인128PNG와 원본3파일 해시 보존. [자동 근거](../../art/warden/shading-restore/review-v1/verification.json).
- image_gen 이미지 편집4회: 색감 복원→발 수정→몸20도 회전→몸통10도 추가/머리10도 반대. 프롬프트·각 결과를art에 보존. 최신 후보는 split-turn-v1.png.
- Forge doctor 최초 stdout 인코딩 실패 후 UTF-8과 새 보고서 이름 doctor-utf8.json으로 재검사: FAIL0,선택적 도구 미설치 경고. 사용 경로는 host image edit이며 영상 모델 없음.
- 비율 비교 자료를 실제 열어 관찰했고, 읽기 전용 담당도 독립 확인했다. 귀·팔 크기 미완료이므로 최종 아트 복원 완료로 판정하지 않는다.
- 최신 후보는 동작에 미적용, 게임 통합/실행 검사는 하지 않았다. 이전 색감 전용 전류·알파 검증을 최신 후보 검증으로 승계하지 않는다.

FR-001 초기명암 후보 있음, FR-002 최신비율 미완료(T008), FR-003 최신리그 미완료(T009), FR-004 기존파일보존 통과, FR-005 최신비율검사 완료/최종동작검사 남음. docs와 진행 상태를 동일하게 갱신한다.

최종 문서 상대 링크17개 존재와 제작 스크립트 구문을 확인했다. `git diff --check`와 `git diff --cached --check` 모두 종료0이다. 줄바꿈 변환 안내만 있고 공백 오류는 없다.
