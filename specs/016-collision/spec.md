# Feature Specification: 게임오브젝트 충돌

**Status**: Ready · **진행 근거**: 2026-11-23 사용자 구현 요청

## User Scenarios & Testing

1. 워든이 바닥에 착지하거나 장애물로 이동하면 접촉점에서 멈춘다. 빠른 대시도 장애물을 통과하지 않는다.
2. 워든·적과 검의 피해 영역은 움직임을 막지 않으면서 기존 활성 시간에 피해를 감지한다.
3. 파괴된 객체는 이후 충돌 후보에서 제외된다. 순간이동은 도착점이 막힐 때 선택·실행하지 않는다.

## Requirements

- **FR-001**: 객체는 월드 기준점을 기준으로 로컬 2D AABB 콜라이더를 선택적으로 여러 개 소유한다. 레이어와 양측 응답으로 Block·Overlap·Ignore를 결정한다.
- **FR-002**: 블로킹 이동은 스윕으로 최초 접촉점을 구한다. 맞닿은 상태에서는 안쪽 이동을 막고 접선 이동과 이탈을 허용한다.
- **FR-003**: 오버랩은 양의 겹침 면적을 요구하며 정적 조회와 시간 구간의 스윕을 지원한다. 게임의 피해 활성 창·중복 피해 제어는 게임 계층이 소유한다.
- **FR-004**: 워든 이동·대시·착지와 순간이동 도착지, 지상·공중 검과 적 돌진을 연결한다. 적 돌진은 워든을 밀거나 막지 않는다.

## Scope

현재 게임에 필요한 키네마틱 2D 사각형을 기술 범위로 정했다. 강체, 회전, 위치 자동 보정, 오버랩 이벤트, 공간 인덱스와 신규 레벨 배치는 범위 밖이다.
