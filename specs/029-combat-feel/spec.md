# Feature Specification: 전투 조작과 분기 안내

**Date** 2026-11-26 | **Status** Ready

## User Scenarios & Testing (mandatory)

### User Story 1 - 공격 후 원하는 방향으로 빠져나간다 (Priority: P1)

검격의 유효타가 끝나면 복귀 모션이 남아 있어도 대시로 이탈할 수 있다. 좌우 이동키와 Shift를 같이 누르면 이동키 방향으로 대시한다.

### User Story 2 - 전원 구역에서 다음 경로를 찾는다 (Priority: P2)

갈림길에 접근하면 냉각 경로와 콘덴서 경로로 향하는 동작을 읽을 수 있다. 릴레이 복구 뒤 시험실 방향을 확인할 수 있다.

## Requirements (mandatory)

- **FR-001** 검격 활성 구간이 끝난 뒤 기존 100ms 입력 선입력으로 대시할 수 있다. 이미 판정한 타격, 공중 대시 횟수, 피격 밀림 제약을 유지한다.
- **FR-002** 대시를 시작할 때 누른 좌우 입력 방향을 사용한다. 중립이면 기존 방향을 사용한다. 시작한 대시의 방향은 고정된다.
- **FR-003** 첫 전원 구역에서 미복구 갈림길과 복구 후 릴레이 귀환로에 안내를 표시한다. 기존 장치 상호작용 안내와 완료·재시작 안내를 우선한다.

## Success Criteria (mandatory)

- **SC-001** 지상과 공중에서 검격 유효타 종료 전후, 예약 만료, 공중 재사용 제한과 반대 방향 대시를 자동 검사 및 SDL 장면에서 확인한다.
- **SC-002** 첫 레벨의 화면에서 갈림길과 복구 후 안내를 확인하고 두 경로의 조작과 진행을 다시 확인한다.
