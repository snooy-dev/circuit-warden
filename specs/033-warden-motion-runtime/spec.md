# Feature Specification: 워든 게임용 모션 통합

**Created** 2026-11-28 | **Status** Ready

**Input** 사용자가 지정한 워든 게임용 모션 18종을 실제 게임에 연결한다.

**Implementation authorization** 런타임 통합 요청 범위에서 구현한다. 이동 속도 단계 추가는 별도 게임 설계 결정이다.

## Intent & Scope

기본 전원 구역과 훈련장에서 같은 새 워든 모션을 사용한다. 대기와 달리기, 점프, 대시, 전투와 순간이동의 시각 신호를 기존 행동에 연결한다. 걷기 첫딛기와 전력 질주는 각각 일반 이동 시작과 지상 대시 뒤 이어지는 이동을 표현한다.

## User Scenarios & Testing (mandatory)

### User Story 1 - 새 워든 동작으로 플레이 (Priority: P1)

**Independent Test** 전원 구역 또는 훈련장에 들어가 대기, 달리기 출발과 반전, 점프와 착지, 지상과 공중의 대시, 세 가지 검격, 피격, 반동과 전하 도착을 각각 확인한다.

**Acceptance Scenarios**

1. **Given** 지상에서 대기 또는 달리기 중일 때, **When** A/D를 누르거나 방향을 바꾸면, **Then** 달리기 출발과 반복 자세가 실제 이동과 보는 방향에 맞는다.
2. **Given** 지상과 공중에서 이동 중일 때, **When** 점프하거나 대시하면, **Then** 이륙·상승·낙하·착지와 지상·공중 대시 및 마무리의 자세를 구분할 수 있다.
3. **Given** 적과 활성 전하가 있을 때, **When** 검격·아래 베기 반동·피격·전하 도착을 발생시키면, **Then** 각각의 자세를 표시하고 해당 조작 상태로 이어진다.

### Edge Cases

- 착지 선입력과 공격 종료처럼 한 갱신에서 행동이 바뀌면 현재 행동에 해당하는 자세를 표시한다.
- 반전의 기준점은 같은 월드 좌표를 유지한다. 정면 도착 자세는 진행 방향과 관계없이 같은 방향으로 표시한다.

## Requirements (mandatory)

### Functional Requirements

- **FR-001** 사용자가 지정한 18개 클립을 게임 배포 자산에 포함하고 두 플레이 장면에서 공유한다.
- **FR-002** 이동에 대기·걷기 첫딛기·달리기 출발·달리기를, 점프에 시작·상승·낙하·착지를, 대시에 지상·공중·마무리를 표시한다. 지상 대시 뒤 이동을 이어 가면 전력 질주 자세를 한 주기 표시한다.
- **FR-003** 지상 및 공중 일반 검격, 아래 베기, 피격, 반동, 전하 도착을 각 자세에 연결한다.
- **FR-004** 입력 우선순위, 이동 수치, 충돌 상자, 점프·대시·공격의 행동 시간과 피해 판정을 보존한다.

### Constraints

- Python + Pico2D의 공통 장면과 스프라이트 재생을 사용한다.
- 사용자가 지정한 시트의 프레임 이미지와 해당 클립 내부의 상대 시간 구성을 사용한다.

## Success Criteria (mandatory)

- **SC-001** 18개 클립이 배포 자산에서 읽히고 전원 구역과 훈련장의 기존 동작에서 새 클립이 선택된다.
- **SC-002** 방향, 접지, 검격·피격·반동·전하 도착의 전환을 실제 게임 화면과 표적 검사로 확인한다.
- **SC-003** 이동·점프·대시 수치, 검격의 유효 시간과 아래 베기 반동, 선입력과 취소가 기존 조작 경로에서 보존된다.
- **SC-DOC** 현재 동작·자산 기준과 구현 및 확인 근거를 문서에서 대조할 수 있다.

## Assumptions & Open Decisions

기존 동작 시간과 시트 원본 시간이 다르면 동작 시간에 맞춰 표시한다. 걷기 첫딛기와 전력 질주는 기존 이동의 표시만 바꾼다.
