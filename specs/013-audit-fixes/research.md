# Research

- **Decision**: 전하의 희소 dict 합성을 NumPy2.5.4 float64 배열로 교체한다.
- **Rationale**: 도구 Python 사전 실험72프레임×8값×3 bob=1,728샘플이 기존 RGBA와 일치했다. 단독 중앙값2.063→0.191ms. 게임 환경에서 다시 검증한다.
- **Alternatives**: 프레임·전환 값 양자화는 모양 변경, 자체 C DLL은 빌드/배포 복잡성 때문에 제외했다. 전류 순수 Python 실험은408샘플 동일하나 중앙값15% 개선뿐이라 우선 유지한다.
- **Decision**: 대기 입력 처리 후 표시 요청 적용, 행동 지역값 전달, 내부 순회 finally.
- **Rationale**: 새 계층 없이 감사 재현 원인을 직접 제거한다. 외부 OS resize의 이벤트 펌프 후 조회는 유지한다.

미해결 범위 결정은 없다. 성능 채택은 게임 환경의 장면 측정·RGBA 검사 통과를 조건으로 한다.
