# Runtime Contract

- 입력 키·규칙·전하100ms·모양·배치·공개 Engine/Level/Canvas API를 유지한다.
- 대기 입력 전달 후 표시 요청을 적용하고 최신 출력으로 update/draw한다. 종료 요청 뒤에는 표시를 바꾸지 않는다.
- 공격을 시작한 외부 update에서 캐릭터/새 베기는 모두0초다. 점프·대시 시간분할·예약 만료는 유지한다.
- 동일 시각·값·seed·끝점의 RGBA는 변경 전과 같다. 프레임·색·알파를 낮추지 않는다.
- 보관된 전달 예외가 순회 목록으로 무관한 객체를 붙잡지 않는다.
