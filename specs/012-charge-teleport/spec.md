## Intent & Scope

가까운 전하를 선택해 즉시 재배치하고 출발·도착 연결 전류를 확인한다. 기존 승인 전하 상태 v5·전환 v2·연결 v4 형태를 사용하며 후속 요청으로 전류 재생을 짧게 압축하고 연속 이동 선입력을 적용한다. 적·피해·무적·벽 충돌·공중 공격·새 아트 제작은 제외한다.

## User Scenarios & Testing (mandatory)

### User Story 1 - 가까운 전하로 즉시 재배치 (Priority: P1)

**Why this priority**: 핵심 이동 경험이다.
**Independent Test**: 전하 접근·이탈, 비활성/활성 클릭, 공격/점프/대시 취소와 착지를 검사한다.

**Acceptance Scenarios**:
1. **Given** 범위 밖 전하, **When** 접근/이탈, **Then** 거리 조건에 따라 활성/비활성이 부드럽게 전환된다.
2. **Given** 활성 전하, **When** 왼쪽 클릭, **Then** 기존 행동을 즉시 취소하고 캐릭터 중심이 전하 중심으로 이동한다. 같은 클릭으로 공격하지 않는다.
3. **Given** 비활성 전하 또는 클릭 판정 밖, **When** 왼쪽 클릭, **Then** 순간이동 없이 기존 공격 입력으로 처리한다.
4. **Given** 공중 도착, **When** 시간이 흐름, **Then** 약하게 상승한 뒤 낙하하며 좌우 조작·기존 착지로 이어진다.

### User Story 2 - 순간이동 경로 확인 (Priority: P2)

**Why this priority**: 즉시 이동의 공간 연결을 전달한다.
**Independent Test**: 가로·세로·대각선·역방향 연결과 선입력 종료 시점과 효과 수명을 확인한다.

**Acceptance Scenarios**:
1. **Given** 순간이동, **When** 이동 완료, **Then** 고정된 출발/도착 중심 사이에 승인 v4 전류가 표시되고 시험값100ms 후 사라진다.
2. **Given** 순간이동 진행 중, **When** 도착 지점 기준으로 활성화된 다음 전하를 클릭, **Then** 현재 이동을 끊지 않고 마지막 유효 전하 하나를 예약해 종료 직후 이동한다.

### Edge Cases

정확한 활성화 거리, 전하 중첩, 동일 위치 재클릭, 같은 프레임 연속 클릭, 창 크기/전체화면 좌표, 화면 밖 도착, 무효 출력, 이동 직전 선입력, 공중 대시 사용 이력을 확인한다.

## Requirements (mandatory)

### Functional Requirements

- **FR-001**: 떠 있는 전하를 배치하고 플레이어 중심과의 거리로 즉시 선택 가능 여부를 판정한다. 활성/비활성 상태 아트는 공유 위상과 중간 반전을 보존한다.
- **FR-002**: 전하 표시보다 넓은 원형 클릭 판정을 사용한다. 활성 전하 왼쪽 클릭은 공격보다 우선하며 비활성/판정 밖은 기존 공격 규칙을 따른다. 판정 중첩 시 클릭 중심에 가까운 전하, 동률은 배치 순으로 선택한다.
- **FR-003**: 순간이동은 공격·점프 준비/상승/낙하/착지·대시 모든 단계를 즉시 취소하고 이전 선입력을 제거한다. 방향·유지 키·공중 대시 소모 이력을 유지한다.
- **FR-004**: 캐릭터 중심을 전하 중심에 맞춘다. 공중 도착에는 약한 위쪽 속도를 주어 잠깐 상승한 뒤 기존 중력으로 낙하·착지한다. 연속 이동의 상승 속도는 누적하지 않으며 화면 상단 여유에 맞춰 제한한다. 바닥 아래/화면 경계 밖 도착은 거절하고 바닥 도착은 기존 지상 상태를 유지한다.
- **FR-005**: 전하는 소모 없이 재사용하며 현재 순간이동 종료 후 별도 쿨다운 없이 재사용한다. 동일 위치 이동은 효과를 생성하지 않는다. 공중 공격은 계속 제외한다.
- **FR-006**: 연결은 고정된 양 끝점을 사용하는 무피해 시각 효과다. 짧게 순간적으로 나타나도록 v4 원본400ms를 시험값100ms로 압축하며 형태와 중심 굵기를 보존한다.
- **FR-007**: 창/전체화면·출력 배율에 맞춰 클릭을 월드 좌표로 변환한다. 무효 출력은 이동하지 않으며 장면 종료/초기화 실패 때 전하·효과 자원을 정리한다.
- **FR-008**: 순간이동 진행100ms 중 다른 순간이동을 시작하지 않는다. 이동을 시작하는 즉시 목표 지점을 기준으로 전하의 논리 활성 여부를 갱신하고 진행 중에는 이 기준을 유지한다. 마지막 유효 전하 클릭 하나를 선입력으로 저장해 종료 직후 재검사·실행한다. 공격으로 중복 전달하지 않으며 포커스 상실·무효 출력·대상 소멸/도착 불가 때 예약을 폐기한다. 승인 아트의 부드러운 상태 전환은 유지한다.

### Constraints

- Python + Pico2D, Codex, 문서 보존·갱신 및 검증 증거 기록은 필수다.
- Agent Sprite Forge / pixelfx는 필요한 에셋 작업에만 사용한다. 스타일은 별도 결정이다.

## Success Criteria (mandatory)

- **SC-001**: 범위 안/밖/경계 및 입력 우선순위 검사에서 의도한 전하로 1회 이동하고 불가능한 대상에는 이동하지 않는다.
- **SC-002**: 모든 기존 행동의 취소 후 위치·상승/낙하·착지와 기존 입력이 정상이며 취소 전 선입력이 재실행되지 않는다.
- **SC-003**: 실제 창에서 전하 상태 변화·반전·연결·종료를 관찰하고 창 크기 변경 후 같은 전하를 선택한다.
- **SC-DOC**: 관련 docs·결정·진행 상태·spec/plan/tasks·검증 결과가 일치하고 추적 가능하다.

## Assumptions & Open Decisions

시험값은 활성 거리 300 월드 단위, 클릭 반경 48(지름96, 표시80×80 유지), 중심은 발 기준점에서 키 절반 위다. 바닥과 창 경계만 있는 현재 장면에 전하 5개를 고정 배치한다. 소모/별도 쿨다운 없음·전류/재입력 잠금100ms·약한 상승 속도로 교체·방향 유지·공중 대시 미회복은 최소 시험안이다. 정확한 활성 거리·클릭 판정·배치·조작감은 사용자 플레이 후 확정한다.


후속 사용자 지시: 순간이동 중 재순간이동 금지, 전류를 짧게 표시, 목표 지점 기준 즉시 활성화, 선입력으로 반응성 개선. 100ms는 빠른 연속 클릭을 위한 기술 시험값이며 최종 사용자 확정 수치는 아니다.

공중 도착 상승의 기술 시험값은 정점까지240ms, 기존 중력에서 최대59.76월드 단위 상승·480ms 후 도착 높이 복귀다. 상단 여유가 부족하면 상승 속도를 줄이며 여유0이면 낙하한다. 목적은 사용자 플레이에서 확인한 빠른 낙하를 완화하는 것이고 새 수치의 조작감은 재확인 전이다.
