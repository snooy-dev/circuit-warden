# Feature Specification: 오프닝 스토리 컷신

**Input**: 사용자가 New Game 뒤 별도의 스토리 컷신을 구현하도록 요청했다.

## User Scenarios & Testing (mandatory)

### User Story 1 - 재가동과 고장을 보고 시작 (Priority: P1)

1. New Game을 선택하면 별도의 전경 컷신에서 오래된 컴퓨터의 재가동과 내부 고장을 차례로 본다.
2. 마지막 컷 뒤 첫 전원 구역으로 진입한다. 기존 낙뢰가 워든을 드러내며 플레이로 이어진다.

### User Story 2 - 이야기 건너뛰기 (Priority: P2)

1. 어느 컷이든 Escape 또는 화면의 Skip으로 건너뛰면 첫 전원 구역 진입이 한 번 실행된다.
2. 설정에서 선택한 화면 모드와 창 크기는 전환 뒤에도 적용된다. R 재시작은 레벨에서만 동작하고 `--training`은 훈련장으로 바로 들어간다.

## Requirements (mandatory)

- **FR-001**: 컴퓨터 외부와 전원부 내부의 별도 이미지 두 장을 순서대로 재생하며 각 컷에 한 줄 자막을 표시한다.
- **FR-002**: 컷신은 약 8.5초 후 자동 종료한다. 짧은 페이드와 느린 화면 확대를 사용한다. 작은 창과 전체화면에서도 원화 비율과 자막·버튼의 가독성을 유지한다.
- **FR-003**: 자동 종료와 건너뛰기는 같은 첫 레벨 진입을 사용한다. 컷신 입력을 플레이에 전달하지 않는다. 창 닫기는 엔진의 종료를 사용한다.
- **FR-004**: 기존 전원 구역 등장·재시작·훈련장 흐름을 보존한다.

## Success Criteria (mandatory)

- **SC-001**: 처음 보는 플레이어가 컴퓨터가 다시 켜졌고 내부에서 고장이 발생했음을 설명할 수 있다. 첫 플레이 평가에서 확인한다.
- **SC-002**: 실제 SDL 창에서 두 컷과 자막, 자연 종료 및 양쪽 입력 방식의 건너뛰기, 첫 레벨 등장, R, 훈련장 경로를 확인한다.
