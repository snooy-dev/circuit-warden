# Feature Specification: 오프닝 스토리 컷신

**Input**: New Game 뒤 별도 컷신을 구현한 후 사용자가 정지 삽화와 플레이로의 급전환을 반려했다. 레퍼런스 게임을 참고한 재연출과 개연성 있는 이야기 제안을 요청했다.

## User Scenarios & Testing (mandatory)

### User Story 1 - 전원 구역의 기동 실패와 워든 등장 (Priority: P1)

1. New Game을 선택하면 전원 구역에서 흡기 팬의 기동과 멎음, 노출된 전선의 스파크를 차례로 본다.
2. 카메라가 전선에서 낙뢰가 닿는 바닥과 워든으로 시야를 넓힌다. 조작이 같은 장면에서 이어진다.

### User Story 2 - 건너뛰기 (Priority: P2)

1. Escape나 화면의 Skip으로 건너뛰면 현재 레벨에서 카메라와 조작이 정상화된다.
2. 설정의 화면 모드와 창 크기가 적용된다. R은 레벨에서만 동작하고 `--training`은 훈련장으로 바로 진입한다.

## Requirements (mandatory)

- **FR-001**: 기존 전원 구역 자산과 픽셀 격자에서 기동, 고장과 워든의 등장을 연출한다.
- **FR-002**: 약 3초 동안 카메라·조명·팬·효과를 연출하고 실제 플레이 카메라로 연결한다. 창과 전체화면에서 건너뛰기를 지원한다.
- **FR-003**: 자동 종료와 건너뛰기는 현재 레벨을 인계한다. 컷신 입력은 플레이에 전달하지 않는다.
- **FR-004**: 기존 전원 구역 재시작·조기 등장·훈련장 흐름을 보존한다.

## Success Criteria (mandatory)

- **SC-001**: 처음 보는 플레이어가 전원 구역이 기동하다 실패했음을 읽고 조작 가능한 순간을 알아차린다. 첫 플레이 평가에서 확인한다.
- **SC-002**: 실제 SDL 창에서 상태 변화, 카메라와 레벨의 연속성, 자연 종료와 두 방식의 건너뛰기, R과 훈련장 경로를 확인한다.
