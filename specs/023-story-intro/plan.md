# Implementation Plan: 오프닝 스토리 컷신

**Spec**: [명세](spec.md)

## Technical Context

Python + Pico2D의 Scene, Canvas, Label, ButtonInput과 이미지 수명을 재사용한다. `New Game → StoryIntroScene → CharacterScene`으로 엔진 프레임 경계에서 전환한다. 컷신 플랫폼·동영상 디코더·음성·추가 게임 목표는 이번 범위 밖이다.

## Storyboard

| 시간 | 연출 | 자막 초안 |
|---|---|---|
| 0.0~4.0초 | 먼지 쌓인 컴퓨터 외부. 낮은 사선 시점에서 전원 버튼 쪽으로 느리게 접근한다. 청록 전원등이 시선을 끈다. | After a long silence, the computer powered on. |
| 4.0~8.5초 | 컴퓨터 내부. 방열판과 콘덴서 사이에서 주황 고장이 보이고 케이블의 노출된 구리에서 짧게 방전된다. | Inside, one failure set off another. |
| 종료 | 케이블의 방전을 첫 레벨의 기존 낙뢰로 연결한다. 낙뢰 뒤에 워든이 모습을 드러낸다. | 없음 |

컷 경계는 짧게 암전한다. 혼용을 피하기 위해 기존 타이틀 메뉴와 같은 영어 화면 문구를 사용한다. 보통 또는 건너뛰기 진입 모두 기존 낙뢰를 재생하며 플레이 입력으로 조기에 끝낼 수 있다. 새 이야기 사실은 원본 기획서의 재가동·연쇄 고장에 한정한다.

## Art Brief

ImageGen 내장 도구로 두 장을 만든다. 16:9 hi-bit 픽셀 일러스트, 청흑색과 구리를 기본으로 하고 하단 자막 영역을 확보한다. 1컷은 오래된 무브랜드 PC 타워와 막 켜진 청록 전원등을 담는다. 2컷은 같은 컴퓨터의 전원 내부를 작은 스케일에서 바라본다. 먼지, 코일과 콘덴서, 손상된 케이블의 작은 방전, 기판의 주황 불꽃을 사용한다. 두 컷에 이미지 내 글자나 인물을 넣지 않는다. 워든의 등장은 기존 실시간 장면에서 보여준다.

## Constitution Check

사용자 요청은 별도 컷신 제작의 근거다. 컷 순서, 영어 자막, 길이와 전환 시간은 검토용 제작안이다. 기존 전투·저장·승패 규칙은 범위에 포함하지 않는다. 적용 코드를 검증하고 현행 문서와 검증 기록을 갱신한다.
