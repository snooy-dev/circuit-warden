# Feature Specification: 첫 레벨 전원 구역

## Intent & Scope

2026-11-24 사용자 요청에 따라 컴퓨터 파워서플라이 내부를 첫 플레이 레벨로 제작한다. 기획서 16~18쪽의 선형 진행과 부품을 사용한다. 보스·패링·저장 및 후속 구역은 별도 기획 범위다.

## Documentation Contract (mandatory)

게임 설계와 진행 상태에 배치 및 적용 범위를 기록하고, 검증 결과를 이 디렉터리에 남긴다.

## User Scenarios & Testing (mandatory)

### User Story 1 - 파워서플라이 내부 통과 (Priority: P1)

1. 흡기구 쪽에서 시작해 점프로 방열판을 넘고 금속 먼지와 마주친다.
2. 코일과 콘덴서 사이에서 전하로 이동하고 우측 출력 단자에 도착한다.
3. R로 시작 배치를 다시 불러오고 기존 훈련장도 실행할 수 있다.

### Edge Cases

화면 크기를 바꿔도 카메라가 공간 밖을 보이지 않아야 한다. 방열판 양방향으로 이동하고 전하 도착 시 지형과 겹치지 않아야 한다.

## Requirements (mandatory)

### Functional Requirements

- **FR-001** 첫 레벨은 흡기구·전력 변환부·출력 단자를 잇는다.
- **FR-002** 플랫폼·충돌·환경 전하·출발/도착 배치를 데이터에 기록한다.
- **FR-003** 기존 플레이 조작을 재사용하고 출력 단자 도착을 표시한다.
- **FR-004** 원거리 배경·연결 가능한 구조물·랜드마크·가까운 차폐를 분리한다.
- **FR-005** 낮게 뭉친 먼지를 바닥·발판 가장자리와 원경 부품에 표현하고 흡기 팬 날개를 고정 프레임 안에서 회전시킨다.
- **FR-006** 첫 레벨 전체를 공통 픽셀 격자로 표시한다. 2026-11-24 사용자 결정으로 기본 창에서 한 칸을 2×2 화면 픽셀로 확정했다. 기존 카메라 시야와 입력 좌표를 유지한다.
- **FR-007** 첫 레벨을 열거나 R로 다시 시작하면, 케이스 상단 케이블의 노출된 구리 심선에서 갈라진 번개가 바닥을 때리고 발밑으로 불꽃이 퍼지며 워든이 나타난다. 타격과 함께 카메라가 짧게 흔들리고 제자리로 돌아온다. 플레이 입력은 등장 연출을 끝내고 정상 처리한다.

### Constraints

Python + Pico2D, 픽셀 아트, 기존 조작과 충돌 API를 사용한다.

## Success Criteria (mandatory)

맵 검증기, 브라우저 경로 검사, Pico2D의 실제 점프·도착·재시작과 화면 시야를 확인한다.

## Assumptions & Open Decisions

## 먼지와 팬 연출

2026-11-24 후속 요청으로 바닥과 발판 가장자리에 먼지를 군데군데 배치한다. 사용자 피드백에 따라 긴 줄기 실루엣을 낮고 납작한 회색 보풀과 먼지 띠로 교체한다. 원경의 배선·콘덴서·방열판·출력 단자에는 오래 쌓인 먼지를 그린다. 흡기구의 고정 프레임 안에서 날개가 회전한다. 기본 실행에서 확인할 수 있어야 하며 표면 충돌과 전하 위치는 기존 맵 데이터를 사용한다.

이 레벨의 도착은 출력부 도달로 표시한다. 분량, 적의 배치, 카메라 수치는 이번 제작의 기술 기본값이다.

## 레벨 동선 재설계

2026-11-24 사용자 요청으로 첫 레벨의 플랫폼과 연결 경로를 재설계한다. 훈련장에도 같은 통과 높이 기준을 적용한다.

- **FR-008** 흡기구에서 안전한 오르내리기를 익히고 첫 방열판을 넘어 전력 변환부로 들어간다. 변환부 바닥은 교전과 후퇴 공간, 상부는 점프와 전하로 지나는 선택 경로다. 두 경로는 두 번째 방열판 앞에서 합류하고 출력 단자로 이어진다.
- **FR-009** 워든이 양방향으로 모든 공중 발판 아래를 달릴 수 있다. 중앙 두 발판 사이 한가운데에 발을 지지할 바닥이 없으면 떨어지며, 일반 점프로 좌우 모두 건널 수 있다.
- **FR-010** 기존 조작으로 두 방열판을 양방향으로 넘을 수 있다. 발판 그림과 충돌 사각형, 먼지와 전하의 배치를 일치시킨다.

도착 조건은 기존 출력 단자 접근을 사용한다. 범위는 현재 전원 구역과 훈련장의 지형 배치이며 새 능력과 후속 방은 별도 설계다.

## 전망대와 전력 변환부 재제작

사용자가 레퍼런스 기반의 첫 레벨 재설계안에 이어 재생성을 요청했다. 첫 화면에서 안전한 점프와 전하 이동을 익힌 뒤, 정비 전망대에서 위아래 두 경로를 보고 선택한다. 이 증분은 기존 전원 구역의 FR-008~FR-010 배치를 대체한다. 훈련장 기준은 유지한다.

- **FR-011** 흡기구의 연습 발판은 착지를 놓쳐도 같은 바닥에서 다시 시도할 수 있다. 전망대에서 하부 적 접근 방향, 상부 첫 발판과 전하, 출력 방향을 같은 시야에서 읽을 수 있다.
- **FR-012** 하부는 기존 이동·점프·대시로 출력까지 이어진다. 상부는 전하를 사용해 진입하고, 지상으로 내려가거나 중간 발판을 거쳐 다시 올라갈 수 있다. 적 처치와 전하 연속 사용은 출력 조건에 포함하지 않는다.
- **FR-013** 새 원경과 구조물은 검증한 지형과 시야에 맞춰 생성하고 배치한다. 상부 배선의 방전 시험은 예고와 위험 범위를 화면에서 구분할 수 있어야 한다. 기존 조작으로 두 경로와 출력에 도달한다.

**성공 판정** 실제 기본 창에서 전망대의 두 경로가 보이고, 하부는 전하 없이 완주하며, 상부로 순간이동한 뒤 중간에서 내려와 다시 오를 수 있다. R 재시작 뒤 같은 동선이 성립한다. 초심자의 경로 해석은 사용자 플레이 평가로 남긴다.

## 정비 샤프트와 순환 동선

2026-11-25 사용자 피드백으로 일렬로 놓인 구역을 실제 수직 높이와 순환 연결이 있는 파워서플라이 내부로 바꾼다. 전원 구역에서 FR-011~FR-013의 배치를 대체하며, 기존 조작과 아트 컨셉을 사용한다.

- **FR-014** 흡기구에서 정비실에 도착하면 중앙 샤프트 또는 변환실 너머 배기 샤프트를 선택할 수 있다. 상부 배선실의 두 끝은 각 샤프트를 통해 정비실로 돌아오는 순환 동선을 만든다.
- **FR-015** 출력실은 흡기구의 위쪽에 놓인다. 어느 샤프트로 올라와도 위층에서 왼쪽으로 진행해 출력에 닿을 수 있다. 떨어진 플레이어가 정비실에서 경로를 다시 고를 수 있다.
- **FR-016** 같은 방 안에서 기존 이동·점프·전하·대시를 사용한다. 카메라는 샤프트를 따라 수직으로 이동한다. 낮은 대비 원경, 금속과 구리, 청록 전하, 2×2 화면 픽셀, 오프닝 접점을 이어가고 방마다 기능이 다른 부품을 배치한다.

**성공 판정** 실제 조작으로 중앙 샤프트를 통한 출력 도달과 배기 샤프트를 돌아 정비실로 복귀하는 경로를 실행하고, 상부 방전·출력 점등·재시작을 확인한다.

## 배전망 복구와 상층 귀환

사용자가 전원 구역의 규모와 기믹을 늘리고 복잡한 아트를 정리하도록 요청했다. 첫 레벨에 중층 교량과 상층 귀환로를 추가하고 FR-014~FR-016의 동선을 이 배치로 갱신한다.

- **FR-017** 초반에 출력 셔터를 먼저 볼 수 있다. 정비실에서 변환실과 배전실을 탐색해 첫 릴레이를 작동시키면 중층 전력교가 생긴다. 전력교 아래에는 하층으로 돌아올 수 있는 착지 공간이 있다.
- **FR-018** 전력교 건너편 상층 차단기를 작동시키면 상층 귀환 셔터와 서쪽 출력 셔터가 열린다. 귀환로는 아는 공간인 중앙 정비실 위로 연결된다. 순서는 릴레이 → 차단기 → 출력이며 R은 전원을 초기화한다.
- **FR-019** 방의 높이와 길이, 통로 폭, 위험 배치가 서로 다르다. 어두운 큰 면과 밝은 착지면으로 공간을 구분하고, 워든·활성 전하·장치 상태에만 강한 색을 사용한다. 기존 흡기 팬, 낙뢰, 구리와 철재, 2×2 픽셀 격자를 사용한다.
