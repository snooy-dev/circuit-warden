# Feature Specification: 첫 레벨 전원 구역

## Intent & Scope

2026-11-24 사용자 요청에 따라 컴퓨터 파워서플라이 내부를 첫 플레이 레벨로 제작한다. 기획서 16~18쪽의 선형 진행과 부품을 사용한다. 보스·패링·저장 및 후속 구역은 별도 기획 범위다.

## Documentation Contract (mandatory)

게임 설계와 진행 상태에 배치 및 적용 범위를 기록하고, 검증 결과를 이 디렉터리에 남긴다.

## User Scenarios & Testing (mandatory)

### User Story 1 - 파워서플라이 내부 통과 (Priority: P1)

1. 흡기구 쪽에서 시작해 점프로 방열판을 넘고 금속 먼지와 마주친다.
2. 코일과 콘덴서 사이에서 전하로 이동하고 우측 출력 단자에 도착한다.
3. R로 시작 배치를 다시 불러오고 기존 훈련장도 실행할 수 있다.

### Edge Cases

화면 크기를 바꿔도 카메라가 공간 밖을 보이지 않아야 한다. 방열판 양방향으로 이동하고 전하 도착 시 지형과 겹치지 않아야 한다.

## Requirements (mandatory)

### Functional Requirements

- **FR-001** 첫 레벨은 흡기구·전력 변환부·출력 단자를 잇는다.
- **FR-002** 플랫폼·충돌·환경 전하·출발/도착 배치를 데이터에 기록한다.
- **FR-003** 기존 플레이 조작을 재사용하고 출력 단자 도착을 표시한다.
- **FR-004** 원거리 배경·연결 가능한 구조물·랜드마크·가까운 차폐를 분리한다.
- **FR-005** 낮게 뭉친 먼지를 바닥·발판 가장자리와 원경 부품에 표현하고 흡기 팬 날개를 고정 프레임 안에서 회전시킨다.
- **FR-006** 2026-11-24 보정 요청에 따라 첫 레벨 전체를 굵은 픽셀 격자로 표시한다. 기본 창에서 한 칸은 약 3×3 화면 픽셀이며 기존 카메라 시야와 입력 좌표를 유지한다.

### Constraints

Python + Pico2D, 픽셀 아트, 기존 조작과 충돌 API를 사용한다.

## Success Criteria (mandatory)

맵 검증기, 브라우저 경로 검사, Pico2D의 실제 점프·도착·재시작과 화면 시야를 확인한다.

## Assumptions & Open Decisions

## 먼지와 팬 연출

2026-11-24 후속 요청으로 바닥과 발판 가장자리에 먼지를 군데군데 배치한다. 사용자 피드백에 따라 긴 줄기 실루엣을 낮고 납작한 회색 보풀과 먼지 띠로 교체한다. 원경의 배선·콘덴서·방열판·출력 단자에는 오래 쌓인 먼지를 그린다. 흡기구의 고정 프레임 안에서 날개가 회전한다. 기본 실행에서 확인할 수 있어야 하며 표면 충돌과 전하 위치는 기존 맵 데이터를 사용한다.

이 레벨의 도착은 출력부 도달로 표시한다. 분량, 적의 배치, 카메라 수치는 이번 제작의 기술 기본값이다.
