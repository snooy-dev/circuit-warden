# Implementation Plan: 첫 레벨 전원 구역

## Summary

구조물 충돌을 먼저 배치하고, ImageGen 원화를 hi-bit 원경과 조립식 구조·부품으로 가공한다. 이동 순서를 먼저 정하고 구역 실루엣을 나눈 뒤 원경과 전경을 쌓는 데 Team Cherry의 제작 기록을 참고했다. [Team Cherry 제작 기록](https://www.teamcherry.com.au/blog/hollow-knight-then-and-now) · [개발진 인터뷰](https://www.pcgamer.com/how-to-design-a-great-metroidvania-map/)

## Technical Context

1280×720 기준, 월드 3840×720, 픽셀 1:1 기준, 수평 추적 카메라와 y 고정. 배치의 좌상단 기준 좌표를 Pico2D의 중앙 원점·위쪽 y로 변환한다. 바닥 y=540, 워든 높이 83·달리기 240/s·완전 점프 166. 도약 구간의 상승량과 수평 공백을 해당 범위 안으로 배치한다. 방열판 앞뒤의 중간 발판은 돌아올 때도 사용한다.

## Constitution Check

기존 레벨·충돌·카메라·스프라이트를 사용하고 첫 레벨 진입점을 바꾼다. 기존 훈련장은 명령행에서 유지한다. 진행 문서에는 사용자 요청과 작업 기본값을 구분한다.

## Project Structure

배치와 가공된 텍스처는 `assets/levels/power-supply/`, 로컬 원화와 프롬프트·검토 자료는 `art/levels/power-supply/`, 런타임은 `game/power_supply_map.py` 및 기존 장면에 둔다. 원경 → 뒷장식 → 구조물 → 워든·적·전하 → 전경으로 그린다. 원경은 720×360 논리 픽셀을 3배로 펼치고 카메라 x 이동의 35%를 적용한다. 소품은 공통 24색을 기준으로 축소하고 배치에 맞춰 음영을 설정한다. 보행면에 구조의 상단 픽셀을 정렬한다.

## Validation

번들·웹 경로·Tiled 내보내기와 SDL 런타임 검사를 수행한다. 브라우저 미리보기는 그리기 순서를 유지해 도형 레이어를 한 층으로 합친 사본을 사용한다. 브라우저의 평면 보행과 Pico2D의 점프 검증을 구분한다.

## 먼지와 팬 연출

원화 편집으로 원경의 팬 날개를 비우고 표면별 먼지를 추가한다. 투명 먼지 시트를 hi-bit로 가공하고 바닥·발판 끝에 장식 오브젝트로 배치한다. 팬 회전자는 빈 하우징의 픽셀 좌표에 중심과 반지름을 맞추고 원경과 같은 패럴랙스 좌표에서 그린다. 실제 SDL에서 서로 다른 시점의 팬 영역과 고정 프레임을 대조하고 흡기구·전력 변환부·출력 단자 화면의 가독성을 확인한다.

## 공통 픽셀 격자

첫 레벨의 배경·지형·캐릭터·효과를 세로 360픽셀의 SDL 텍스처에 함께 그린 뒤 최근접 확대한다. 너비는 창 화면비에 맞추며 텍스처는 같은 크기에서 재사용한다. 게임 좌표와 창 입력은 기존 출력 크기를 기준으로 계산한다. 화면 크기 전환과 실제 전하 클릭을 SDL로 검사한다.

## 상단 케이블의 낙뢰로 시작

기존 상단 케이블에서 아래쪽 워든으로 이어지도록 전류 시작 좌표를 지정하고 입구 장식 인렛을 맵에서 제거한다. 기존 전류 애니메이션과 340ms 등장, 즉시 입력 처리, 스폰과 충돌 배치를 재사용한다. 실제 SDL에서 케이블과 방전의 연결, 워든 등장, R 재시작과 조기 이동을 확인한다.

등장 전용 pixelfx 시트에 선행 방전, 굵은 번개와 국부 섬광, 바닥 불꽃을 굽는다. 낙뢰 타격 시점에 워든이 떠오르기 시작한다. 기존 340ms 등장과 입력 조기 종료를 유지하며 일반 전하 연결에는 기존 에셋을 사용한다. 실제 SDL에서 첫 타격·잔광과 재시작·입력 중단을 확인한다.

시작 케이블의 굽은 부분에만 찢어진 피복과 노출 심선을 합성한다. 심선 끝에 시작 좌표를 지정하고 기존 타격 시트를 다시 굽는다. 맵 배치와 실제 SDL에서 방전과 심선의 접점을 확인한다.

타격 시각부터 100ms 동안 첫 레벨의 렌더 카메라를 논리 픽셀 단위로 흔든다. 등장 클립의 시간으로 흔들림을 계산하고 그리기가 끝나면 기존 카메라 중심을 복원한다. SDL에서 타격 동기화, 픽셀 단위 변위, 원위치, R 재시작과 조기 입력을 확인한다.
