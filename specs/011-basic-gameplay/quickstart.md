# Quickstart

프로젝트 루트 PowerShell, 게임 .venv 사용.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

A/D 이동·상쇄·해제 → 양 방향 왼쪽 클릭 → 공격 중 이동키 변경/해제·재클릭 → 종료 복귀를 확인한다. F6/F11과 포커스 전환 후 유지 입력이 남지 않아야 한다. 우클릭은 공격하지 않는다.
선택한 자동 검사와 실제 명령·결과는 [verification](verification.md)을 따른다. 기본 창은 1280×720이다. 지상 공격은 승인 HK v6·팔 보정 v3와 FX v11이 합성된 클립을 재생하고 공중 공격은 승인 v9·눈색/전류 v4 모션을 재생한다. 기본 적의 피해 판정은 [전투 규칙](../../docs/systems/basic-enemy.md)을 따른다.

Space로 제자리 점프, A/D+Space로 달리기 점프를 확인한다. 시작120ms 후 이륙하고 착지180ms 동안 잠긴다. 공중 A/D 변경·해제는 공격 잠금 중을 제외하고 즉시 반영되며 상승/낙하 전용 좌우 모션을 사용한다. 상승/낙하 중 클릭은 공중 공격을 시작한다. 재점프는 실행하지 않고100ms까지만 예약한다. 버튼을 계속 누르면 착지 후 자동으로 뛰지 않으며 Space를 놓고 다시 눌러야 한다. 점프 높이는 idle 몸체 키(귀 포함, 투명 여백 제외)의 2배다.

Shift로 현재 방향 대시를 확인한다. 거리는 키2배/166 월드 단위, 이동0.2초이며 전용 준비0.1초/복귀0.167초까지 총0.467초 행동을 잠근다. 이동 시작부터 전류 잔광을 함께 표시한다. 공중1회 제한·착지 후 회복, 대시 중 공격/점프/방향 변경 차단과 종료 후 유지 키 복귀를 확인한다. 화면 가장자리에서는 거리가 줄어든다.

공중 대시의 이동200ms 동안 높이를 유지하고 복귀 때 수직 운동을 이어간다. 일반 점프보다200ms 늦게 착지하는지 확인한다.

착지 직전 또는 착지 초반에 Space를 놓고 다시 눌러 착지 웅크림에서 곧바로 시작 웅크림으로 이어지는지 확인한다. 연결 뒤80ms 후 이륙하며 Space 유지로 세 번째 점프가 발생하지 않아야 한다. 늦게 누르면 기존 착지 완료 후 처음부터 준비한다.

지상340ms·공중300ms 모션을 양 방향으로 확인한다. 지상에서 FX v11이 40ms부터 표시되고 모션 종료·취소 시 베기가 남지 않는지, 공중에서 승인 모션만 표시되는지 확인한다. 공중 공격 중 A/D로 방향·수평 위치가 바뀌지 않고 중력은 계속되는지, 높은 위치에서 끝나면 상승/낙하로 복귀하는지, 낮은 위치에서 시작해 먼저 바닥에 닿으면 즉시 착지 모션으로 연결되는지 확인한다. 전하 클릭 우선과 공격당1회 피해는 기존과 같아야 한다.
