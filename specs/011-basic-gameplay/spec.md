# Feature Specification: 기본 게임플레이 조작과 애니메이션

**Created**: 2026-11-11
**Status**: Ready
**Input**: 입력·애니메이션 기반 감사 후 플레이 레벨에 게임플레이 모드 적용, Warden A/D 이동·마우스 공격·애니메이션 연결.
**Design approval**: 게임플레이 모드·A/D·클릭 공격과 공격 중 정지/종료 후 유지 키 반영은 사용자 결정이다. 기술 계획은 별도 승인받지 않았다.
**Implementation authorization**: 개발 요청과 후속 답변 범위의 구현·검증·로컬 커밋. PR 제외.

## Intent & Scope

기존 입력·재생 기반을 먼저 감사하고 실제 플레이 레벨에서 이동·정지·공격 애니메이션을 조작한다. 타이틀 모드는 향후 다른 레벨의 규칙 예시다. 적·피해·충돌·콤보·점프·VFX·새 아트·타이틀 모드 구현은 제외한다.

## User Scenarios & Testing (mandatory)

### User Story 1 - 플레이 모드에서 이동 (Priority: P1)

**Why this priority**: 플레이 레벨과 규칙 소유를 확립한다.
**Independent Test**: A/D 유지·상쇄·해제, Run/idle 전환과 포커스 정리.
**Acceptance Scenarios**:
1. **Given** 플레이 레벨, **When** A/D 입력, **Then** 방향별 이동·Run, 양쪽 입력/해제 때 정지·idle.
2. **Given** 유지 입력, **When** 포커스 상실/최소화, **Then** 유지 입력 제거.

### User Story 2 - 멈춰서 공격하고 복귀 (Priority: P2)

**Why this priority**: 최초 행동 상태를 완성한다.
**Independent Test**: 양 방향 공격 첫 프레임·종료·재클릭 무시·이동 재개를 상태 검사와 실제 창으로 확인한다.
**Acceptance Scenarios**:
1. **Given** idle/Run, **When** 왼쪽 클릭, **Then** 현재 방향 공격 1회, 재생 중 위치·방향 고정.
2. **Given** 공격 중, **When** 추가 클릭/A/D 변경, **Then** 재시작 없이 종료 후 현재 유지 키 반영.
3. **Given** 공격 중 키 해제, **When** 공격 완료, **Then** 마지막 방향 idle 복귀.

### Edge Cases

우클릭 무시, A+D 상쇄, 공격 중 키 해제/반대키/포커스 상실, 창 축소·무효 출력, 큰 프레임 간격, 잘못된 자산 설정·진입 실패 정리.

## Requirements (mandatory)

### Functional Requirements

- **FR-001**: 입력 수집·전달·유지 상태와 반복/단발 재생의 기존 지원 및 부족 기능을 코드·검사 근거로 감사한다.
- **FR-002**: 플레이 레벨은 구체 게임플레이 모드를 사용하고 Warden을 직접 참조한다. 레벨별 모드 선택 구조를 유지한다.
- **FR-003**: A/D 이동·상쇄·해제·방향별 Run/idle·화면 경계·포커스 입력 정리를 제공한다.
- **FR-004**: 왼쪽 클릭으로 현재 방향 공격 1회. 공격 중 정지·추가 클릭 무시, 종료 후 현재 유지 키 반영.
- **FR-005**: 기존 공격 7프레임·각 50ms를 보존한다. 첫 프레임부터 시작하고 단발 완료를 판단하며 좌우 방향·발 기준점을 표시한다.
- **FR-006**: 잘못된 반복 여부 설정을 거부하고 진입 실패·종료 때 이미지 자원을 해제한다.
- **FR-DOC**: 현재 규칙·구조·출처·진행·검증과 작업 문서를 일치시킨다.

### Constraints

Python + Pico2D 유지. 사용자 제안 transitions 사용은 기술 계획에서 다룬다. 게임 .venv 외 전역 환경을 변경하지 않는다.

## Success Criteria (mandatory)

- **SC-001**: 실제 플레이 모드에서 이동·상쇄·해제·포커스 상실을 재현하며 중복 입력 처리가 없다.
- **SC-002**: 양 방향 공격이 한 번 재생되고 공격 동안 이동 0, 종료 후 유지 키 반영, 재클릭 시 재생 시간 초기화 없음.
- **SC-003**: 실제 창에서 idle/Run/공격의 표시·방향·접지와 종료 자원 정리를 확인한다.
- **SC-DOC**: 요구·계획·작업·코드·검증과 현재 docs가 대응한다.

## Assumptions & Open Decisions

왼쪽 클릭·현재 방향·추가 클릭 무시를 제시한 질문에 사용자는 공격 중 정지를 선택했다. 속도·배율·바닥선은 기존 기술 기본값 유지. 방향키 별칭은 이번 A/D 조작으로 대체한다. 왼쪽 공격은 기존 시트 수평 반전이며 별도 아트는 만들지 않는다. 포커스 상실은 유지 키/미시작 공격을 지우고 이미 시작한 공격은 계속 종료한다. 무효 출력에서는 새 공격을 시작하지 않는다. 창 축소 시 경계 보정은 공격 중에도 적용한다. 최종 미술 품질·피해 규칙은 미정이다.
