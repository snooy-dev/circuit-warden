# Feature Specification: 공중 아래 베기

**Date** 2026-11-26 | **Status** Ready

## User Scenarios & Testing (mandatory)

공중에서 S를 누른 채 J 또는 일반 공격 클릭으로 발밑을 벤다. 적을 맞히면 위로 튀어 다음 적을 노리거나 공중 대시로 벗어난다. 헛치거나 지면에 먼저 닿으면 상승 반동 없이 일반 조작으로 돌아온다.

## Requirements (mandatory)

- **FR-001** 아래 베기는 독립 준비·타격·복귀 상태와 발밑 전기 표시를 사용한다. A/D 조향과 중력을 적용한다.
- **FR-002** 지형에 가려지지 않은 아래쪽 첫 적에게 피해 1을 준다. 적중 한 번으로 상승 반동과 공중 대시 1회를 회복한다.
- **FR-003** 지면·빈 공간에서는 반동이 없다. 피격·순간이동·재시작에서 종료한다. 활성 전하 클릭은 전하 이동으로 처리한다.

## Success Criteria (mandatory)

- **SC-001** 입력, 수직 타격과 반동, 지형 차단, 헛스윙과 공중 대시 회복을 실제 조작 경로에서 확인한다.
- **SC-002** SDL 화면에서 아래 베기 궤적과 적중·상승을 확인한다.
