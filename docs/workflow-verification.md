# Verification: 반복 스프라이트 문서화 제외·기존 문서 정리

기준일: 2026-11-10. 사용자 요청은 반복 스프라이트 작업의 문서화 중단과 기존 관련 문서 제거다. 새 게임 기능·아트 제작·통합은 범위 밖이다.

## 반영 결과

- AGENTS·constitution 2.2.0·workflow·프로젝트 템플릿 4개·overlay에 스프라이트 작업 예외를 명시했다. 게임 기능 개발의 Spec Kit 흐름은 유지한다.
- 스프라이트 생성·보정은 요청 → 제작·검사 → 채팅 결과 보고로 진행한다. 채택 상태·장기 기준만 기존 docs에 갱신하며 별도 보고서를 만들지 않는다.
- 사용자 삭제 지시에 따라 스프라이트 작업 002~009와 별도 워든 검증 문서에서 Markdown 66개를 제거했다. 새 보관 문서나 복제본은 만들지 않았다. 기존 아트 기준은 원화·현재 상태·결과 링크 중심으로 축소했다.
- 제작·검사 스크립트 3개와 검사 JSON 2개는 scripts로 옮겼다. 삭제한 spec.md 해시를 요구하던 메타데이터 필드를 제거했으며 실제 원본·제작 코드의 해시 기록은 유지했다.
- 새 브랜치 없이 main에서 처리한다. 게임 구현 명세와 무관한 미커밋 변경은 보존한다.
