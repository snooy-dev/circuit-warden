# Verification: 프로젝트 지침 정비

기준일: 2026-11-11. 현재 범위는 사용자 요청에 따른 기존 기능 브랜치 동기화 절차의 문서화다. 실제 fetch·merge·rebase와 게임 변경은 범위 밖이다. 아래 이전 검사는 당시 작업의 근거이며 이번에 재실행한 결과가 아니다.

## 기존 브랜치 동기화 절차 기록

- AGENTS에서 workflow의 상세 절차를 참조하고 progress에 요청 범위를 반영했다. 사용자 변경 보존·fetch·origin/main 기준 비교·merge·충돌 해결·영향 범위 검증·장기 작업/PR 준비 시 재확인과 rebase 예외를 명시했다.
- `git status --short --branch`: main 브랜치, 수정 전 작업 트리 깨끗함을 확인했다. 문서 내용과 새 상대 링크의 대상·앵커를 확인했으며 `git diff --check`는 종료 0으로 공백 오류가 없었다.
- 게임 코드 변경이 없어 게임 자동 테스트·실제 창 검사는 선택하지 않았다. 실제 원격 동기화와 충돌 해결 동작은 실행하지 않았다.
