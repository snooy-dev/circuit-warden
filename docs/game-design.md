# 게임 설계

상태: **기획 정리 전 / 미구현**

## 확정 제약

- 프로젝트: Circuit Warden. 구현 기술: Python + Pico2D.
- 사용자가 기획·게임 설계·범위를 결정하고 Codex가 문서화·구현 계획·코드를 담당한다.
- PPTX는 제안서에 가깝다. 손그림 2D 스타일은 고정되지 않았다.

## 원본 자료

- [Circuit_Warden_Phase1_Presentation.pptx](../Circuit_Warden_Phase1_Presentation.pptx)

## 미정 설계

플레이어 경험 목표, 핵심 반복 구조, 시스템 목록, 조작·승패 규칙, 제작 범위는 이후 사용자와 확인한다. 코드나 에셋 제작을 위해 임의의 값을 확정하지 않는다.

규칙은 [systems](systems/README.md), 아트는 [art-direction](art-direction.md)에 현재 기준과 선택 이유를 남긴다. 과거 변경 경위는 Git 로그·diff로 확인한다.
