## 확정 범위와 가정

- 본격 게임 구현 및 이번 조작 범위는 사용자 요청이 진행 근거다. 공격 중 정지·종료 후 유지 키 반영은 후속 답변으로 확정했다. 계획의 세부 기술 가정은 사용자 승인으로 표시하지 않는다.
- Python + Pico2D 유지, transitions 0.9.3은 Warden 상태 머신에만 사용하며 게임 .venv에 설치했다. 게임·도구·전역 환경을 분리한다.
- 수평 A/D·왼쪽 클릭과 상태 규칙은 이번 범위다. 속도·배율·바닥선은 [기술 구조](architecture.md#캐릭터-이동-검사)의 기존 기술 기본값이다. 좌측 공격은 수평 반전하며 화면 끝에서 공격 일부가 잘릴 수 있다.
- 피해·적·충돌·물리·점프·콤보·타이틀 모드·VFX·새 아트 생성은 제외한다. 다른 규칙의 레벨은 추후 다른 GameMode를 지정한다.
- 검증된 증분은 로컬 커밋한다. 원격 push·PR·main 병합은 수행하지 않았다. [동기화 절차](workflow.md#기존-브랜치-동기화)와 한국어 커밋 규칙을 유지한다.

## 실행과 다음 작업

기본 실행은 main.py, 레벨 규칙 입력은 game/mode.py, Warden 상태·재생은 game/character.py, 배치·장면 수명은 game/scene.py다. [검사 안내](../tests/README.md)에 따라 필요한 검사만 선택한다.

현재 구현을 직접 플레이해 감각을 확인한 뒤, 다음 게임 규칙의 대상·판정·결과를 정한다. 구현된 입력을 피해 판정이나 전체 전투 설계 승인으로 확대하지 않는다.
