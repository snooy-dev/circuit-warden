# 진행 상태

갱신일: 2026-11-24

## 현재 단계

- **검 적중 연출:** 2026-11-24 사용자 요청으로 할로우 나이트의 일반 검격을 참고했다. 45ms 히트스톱과 접점 스파크에 적의 짧은 밀림을 연결하고 일반 검격은 평상시 카메라 추적을 사용한다. [검증](../specs/020-combat-reimplementation/verification.md#할로우-나이트-일반-검격-참고).

- **이동 공격과 베기 조정:** 2026-11-24 사용자 요청으로 지상·공중 공격 중 A/D 이동을 적용하고, 공격 재생률을 30% 낮췄다. 지상·공중의 베기 효과는 각각 가로·세로를 20% 확대했다. 자동 검사 30개와 전원 구역·훈련장 SDL 검사를 통과했다. 사용자 조작감 확인이 남아 있다. [명세](../specs/020-combat-reimplementation/spec.md) · [검증](../specs/020-combat-reimplementation/verification.md#이동-공격과-속도효과-조정).

- **오프닝 스토리 컷신:** 2026-11-24 사용자 피드백으로 정지 삽화 시안을 전원 구역의 실시간 연출로 교체했다. 팬 기동과 전선 스파크, 낙뢰와 워든 등장을 같은 카메라에서 보여준 뒤 조작을 넘긴다. 출력에 전류가 닿지 않는다는 서사는 제안 상태다. [명세](../specs/023-story-intro/spec.md) · [연출 구성](../specs/023-story-intro/plan.md) · [검증](../specs/023-story-intro/verification.md).

- **타이틀 메뉴:** 2026-11-24 사용자 후속 요청으로 화면의 키 가이드를 삭제했다. New Game, Settings, Quit은 전원 구역 원경 위 텍스트로 표시하고, 설정은 항목명과 값을 열로 정렬한다. 기본 창·축소 창·전체화면의 실제 SDL 출력과 키보드·마우스 입력을 확인했다. [명세](../specs/022-title-menu/spec.md) · [계획](../specs/022-title-menu/plan.md) · [검증](../specs/022-title-menu/verification.md).

- **첫 레벨 낙뢰 등장:** 2026-11-24 사용자 요청으로 노출된 구리 심선에서 떨어지는 번개에 타격 순간의 짧은 카메라 흔들림을 추가했다. 실제 SDL에서 타격 동기화, 시야 복귀, R 재시작과 조기 이동을 확인했다. [실제 화면](../art/levels/power-supply/entry-camera-shake/entry-camera-shake.gif) · [검증](../specs/021-power-supply-level/verification.md#낙뢰-카메라-흔들림-검증).

- **파워서플라이 먼지·흡기 팬:** 2026-11-24 요청과 사용자 피드백으로 바닥·발판에 낮은 보풀과 먼지 띠를 배치했다. 원경 부품에도 먼지층을 더했다. 팬 금속과 먼지는 원경 팔레트의 12색을 사용하며, 회전하는 날개 뒤로 먼지 낀 고정 통풍망이 보인다. - **첫 레벨 전원 구역:** 2026-11-24 사용자 요청으로 컴퓨터 파워서플라이 내부를 기본 실행에 연결하고 환경 원화에 hi-bit 가공을 적용했다. 흡기구, 방열판, 코일·콘덴서, 출력 단자를 배치했다. [명세](../specs/021-power-supply-level/spec.md) · [계획](../specs/021-power-supply-level/plan.md) · [검증](../specs/021-power-supply-level/verification.md).

- **지상 기본 공격 분기 방전 초승달:** 2026-11-24 사용자 요청으로 선택한 효과를 기본 레벨과 훈련장이 공유하는 지상 공격 시트에 적용했다. 효과가 들어가는 6셀을 교체했고, 실제 기본 레벨 SDL 창에서 좌우 시작·정점·소멸을 확인했다. 사용자 직접 플레이 평가는 남아 있다. - **워든 지상 기본 공격 FX v11 승인:** 2026-11-18 사용자 지시로 [v11 승인본](../art/warden/provisional-approved/basic-attack-fx-v11/review.html)을 별도 보관했다. 사용자 지정 곡선·3번(40ms) 시작·폭 22·전류 디테일 보강이 승인 범위이며,17프레임·340ms·뒤/앞 레이어와 승인 캐릭터를 유지한다. 전체 복사 해시를 대조하고 [승인 기록](../art/warden/provisional-approved/basic-attack-fx-v11/approval.json)을 남겼다.

- **워든 Idle 신체·전류 수정 후보:** 사용자가 LTX 후보의 전류 표현·과도한 꼬리/천 움직임·신체 정지를 지적해 반려했다. [수정 미리보기](../art/warden/idle-current-v2/final/review.html)는 기존 측면 원화·리그의 작은 호흡과 체중 이동에 pixelfx 내부 방전을 합성했다. 128×104·96프레임/24fps·4초, 머리 상하 이동 범위2px·발 고정이며 전류를 숨겨 신체만 비교할 수 있다. 공통16색·이진 알파·잘림 없음·시트/프레임/GIF 일치·정상/느린 재생과 프레임 이동을 확인했다. 기존 후보는 보존했고 새 후보의 전기감·동작 크기는 사용자 검토 대기이며 게임 통합은 하지 않았다. 고정 무늬가 아닌 전류와 신체 자체의 idle 동작 기준은 [아트 기준](art-direction.md#동작별-적용-범위)에 반영했다.

- **워든 디자인 규격 실측·문서화:** 사용자의 원화 측정 요청에 따라 [파일 없이 적용하는 비율·형태·명암·변형 규격](art-direction.md#워든-원화-기준)을 작성했다. 기본 원화와 현재 측면 원화의 머리 폭을 각각 기준으로 귀·눈·가시 복부·팔·발·꼬리·천을 측정하고,16색 전체와 명암 배치·idle 색 면적, 검 원화의 내부 비율을 명시했다. 자동 윤곽 실측·수동 겹침 경계·숨은 관절의 측정 불가를 구분한다. 제작 지시에는 문서 규격을 넣고 이미지는 보조 참조로 사용한다. 후속 확인 요청에 따라 손가락·발가락 없는 단순한 손발을 모든 자세·검 그립에도 적용하고, 신체 전류의 부위별 진행 방향·필수 디테일·연속 재생 검수 조건을 보강했다. 원본 해시·윤곽·눈·발·색·게임 첫 셀·검 비율34검사, 독립 시각 검토, 로컬 링크/앵커104개·공백 검사를 확인했다. 기존 적/발표 자료 누락 링크3개는 범위 밖으로 남겼다. 새 아트 생성·게임 변경은 수행하지 않았다.

## 확정 범위와 가정

- **전투 피드백:** 전류 첫 화면과 워든 도착 자세의 기준점을 맞췄다. 적 상단에서는 한 번 튕겨 벗어나고, 공중 피격 시 정점과 하강 중에도 옆으로 이동한다. 사용자 전진 시안 피드백을 반영해 지상 기본 공격에 타격 전 짧은 전진을 적용했다. [실전 영상 조사](../specs/019-combat-feedback/research.md) · [명세](../specs/019-combat-feedback/spec.md) · [계획](../specs/019-combat-feedback/plan.md) · [검증](../specs/019-combat-feedback/verification.md).

- **전하 생성:** 사용자 요청으로 E 기술과 환경 구역의 전하 생성을 적용했다. 환경 배치는 R과 재생성 때 바뀌며 두 생성원 모두 이동에 성공하면 해당 전하가 소멸한다. 입력·구역·대기 시간과 기술 전하 한 개는 시험안이다. [명세](../specs/018-charge-generation/spec.md) · [계획](../specs/018-charge-generation/plan.md) · [검증](../specs/018-charge-generation/verification.md).

- **워든 전투:** 2026-11-23 사용자 요청으로 일회성 전하 이동·돌진 회피·공중 공격 후 이탈을 연결했다. 직접 공격 J와 도착 직후 돌진 보호는 기술값이다. 새 전하 소모·검 적중 효과를 게임에 적용하고 실제 SDL에서 공중 명중·이탈과 돌진 회피를 확인했다. 사용자 조작감 평가는 남아 있다. [명세](../specs/017-warden-combat/spec.md) · [계획](../specs/017-warden-combat/plan.md) · [검증](../specs/017-warden-combat/verification.md).

- 2026-11-23 사용자 요청으로 구현과 직접 관련된 검사만 기본 실행하고 유효한 검사 결과를 재사용한다. 전체 회귀는 명시적 요청이 있을 때 실행한다. 필수 작업이 샌드박스에서 거부되면 권한 승인을 요청한다. [검사 실행 범위](workflow.md#검사-실행-범위) · [권한과 개발 흐름](../AGENTS.md#권한과-개발-흐름).

- 2026-11-18 사용자 요청에 따라 [서브에이전트 모델 선택 기준](workflow.md#서브에이전트와-모델-선택)에 GPT-6.2 Sol·Astra를 반영했다. 화면 검증에는 GPT-6.1 Terra를 사용한다.

- 사용자 요청으로 루트 README의 내부 작업 안내·상태·검사 설명을 제거했다. README는 사용자·퍼블리싱용이며 명시적 수정 요청이 있을 때만 변경한다. 작업 정보는 기존 docs·specs·tests 문서에서 유지하며 세부 보호 규칙은 [작업 규칙](../AGENTS.md#문서git-보호)을 따른다.
- 사용자 지시에 따라 pixelfx 공통 라이선스·고지만 유지하고 게임·자산 README의 별도 제작 도구 사용 문구는 두지 않는다.

- 본격 게임 구현 및 이번 조작 범위는 사용자 요청이 진행 근거다. 공격 중 정지·종료 후 유지 키 반영은 후속 답변으로 확정했다. 계획의 세부 기술 가정은 사용자 승인으로 표시하지 않는다.
- Python + Pico2D 유지, transitions 0.9.3은 Warden 상태 머신에만 사용하며 게임 .venv에 설치했다. 게임·도구·전역 환경을 분리한다.
- 수평 A/D·왼쪽 클릭과 상태 규칙은 이번 범위다. 속도·배율·바닥선은 [기술 구조](architecture.md#캐릭터-이동-검사)의 기존 기술 기본값이다. 좌측 공격은 수평 반전하며 화면 끝에서 공격 일부가 잘릴 수 있다.
- 011 기본 조작 범위에서 피해·적·충돌·범용 물리·콤보·타이틀 모드·새 아트 생성은 제외했다. 013 기본 적 전투에는 원화 기반 적 한 마리와 양방향 피해·체력 판정을 포함한다. 베기 VFX는 후속 요청으로 포함했다. 다른 규칙의 레벨은 추후 다른 GameMode를 지정한다.
- 검증된 증분은 로컬 커밋한다. 원격 push·PR·main 병합은 수행하지 않았다. [동기화 절차](workflow.md#기존-브랜치-동기화)와 한국어 커밋 규칙을 유지한다.

## 미결 사항

- 전하 순간이동 시험값(거리·클릭 판정·배치·소비·상승 관성)의 조작감.
- 010/011 사용자 직접 플레이 감각·최종 미술 품질. 공격 원본의 형태 변화와 좌측 반전 표현은 후속 검토 대상이다.
- 009의 이전 사용자 직접 확인·확인 후 임시 자료 정리(T013/T014/T016). 자료를 보존한다.
- 최종 속도·피해·승패와 전체 아트 규격, 실물 고DPI·대량 객체 성능·장치 리셋 자동 복구는 미정 또는 미확인이다.

## 실행과 다음 작업

기본 실행은 main.py, 레벨 규칙 입력은 game/mode.py, Warden 상태·재생은 game/character.py, 배치·장면 수명은 game/scene.py다. [검사 안내](../tests/README.md)에 따라 필요한 검사만 선택한다.

기본 적 전투와 전하 순간이동을 결합한 예고·회피·반격 조작감과 아트 비례를 직접 확인한다. 최신 커밋 통합은 사용자 요청이며 전체 게임의 최종 밸런스는 확정하지 않는다.

구현한 전하 순간이동의 활성 거리·클릭 판정·배치·소비·상승 관성 조작감을 다시 플레이로 확인하고 후속 조정을 정한다.

- **검 원화 채택:** 2026-11-11 사용자 결정으로 첨부한 새 검 원화를 향후 검 디자인 기준으로 기록했다. 보관본과 적용 기준은 [워든 원화 기준](art-direction.md#워든-원화-기준)을 따른다.
