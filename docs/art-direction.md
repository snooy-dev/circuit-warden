# 아트 기준

## 작업 방식

반복 스프라이트 생성·보정은 사용자 요청에 따라 직접 제작·검사하고 결과를 채팅으로 보고한다. 별도 specs·계획·체크리스트·검증 보고서를 만들지 않는다. 현재 채택 상태와 장기 기준만 이 문서에 유지한다. 게임 규칙·코드·런타임 통합은 [개발 흐름](workflow.md)을 따른다.

## 워든 원화 기준


근거: 2026-11-09 사용자가 첨부 이미지 2점을 주인공 워든의 **원화**로 지정하고 컨셉·신체 표현·무기의 용도를 설명했다. 캐릭터의 정체성과 무기 용도는 [게임 설계](game-design.md#주인공-워든warden)가 소유한다.

|---|---|---|

2026-11-11 사용자 결정: [energy-sword-master-v2.png](../art/warden/reference/energy-sword-master-v2.png)를 앞으로 사용할 **검 원화 기준**으로 채택한다. 사용자 첨부 `ChatGPT 이미지 2026년 11월 11일 오후 10_50_08.png`의 변경 없는 보관본이다. 가늘고 길게 뾰족해지는 청록색 칼날, 불꽃형 기부, 흰 중심 전류와 분기, 가는 에너지 손잡이를 기준으로 삼는다. 검 디자인은 기존 무장 원화보다 이 기준을 우선하며 기존 캐릭터 신체 기준은 유지한다.

원화에 보이는 신체의 **흰 무늬는 몸에 전기가 흐르는 모습의 일부**를 보여준다. 단순한 장식 무늬로 해석하지 않는다. 전류는 장식 무늬가 아닌 방향성 흐름으로 표현한다.

2026-11-11 공격 수정 기준: 검은 화면 좌우가 아닌 **캐릭터의 해부학적 오른손**으로만 잡는다. 왼손은 자유롭게 두며 어깨→팔→손→자루 연결이 프레임 사이에 바뀌지 않아야 한다. 사용자 궤적 그림에 따라 오른쪽을 보는 자세에서 검끝이 위쪽→몸 앞→아래→왼편으로 크게 지나가고, 손의 이동과 앞다리로의 체중 이동이 함께 보여야 한다. 후반에는 검을 쥔 손과 팔 자체가 골반을 지나 몸 뒤로 넘어가야 하며 손을 몸 앞에 고정하고 검만 돌리는 동작은 제외한다. 검끝 궤적과 별도로 어깨·팔꿈치·손·골반의 관계 및 인접 프레임의 형태 일치를 검사한다. 공격 클립에는 전신이 연동된 베기 구간만 포함하고 준비·회수·별도의 종료 대기는 제외한다. 7번은 동작 중 베기를 마무리하는 프레임이다. 귀·망토 천·꼬리의 관성과 전류 흐름을 유지하되 흰 무늬와 원치 않는 잔여 픽셀을 구분해 검사한다.

사용자는 팔이 몸 뒤로 넘어가는 v2의 전체 자세를 채택했고, 몸의 형태가 달라진 v3는 반려했다. 이후 보정은 기존 신체 비율을 유지한다. 4~6번은 오른팔을 더 들고 팔·검의 원근으로 화면에 보이는 길이를 줄이며, 7번은 오른팔을 들어 검이 화면 왼쪽 위 대각선을 향하게 한다. 몸은 run처럼 진행 방향을 더 바라보도록 수직축을 중심으로 약 20도 돌리는 것이 목표이며, 화면 평면의 20도 회전은 아니다. 귀·얼굴·팔다리 두께의 불필요한 변화와 희미한 외부 얼룩을 검사한다. 전류는 단순 밝기 변화가 아니라 idle처럼 흰 전류 머리와 청록색 잔상이 문양 경로를 따라 이동해야 한다. v4의 동작 방향은 채택했으며, 복부와 골반을 별도 판처럼 나누는 어두운 경계는 제거한다. 몸통에서 낮은 골반과 짧은 두 다리로 매끄럽게 이어져야 하고, 양다리의 굵기·길이는 같은 신체 기준을 유지한다. 의도된 흰 전류 문양과 망토의 접촉 그림자는 이 복부 경계와 구분한다.

이 두 이미지는 원화 기준이며 게임용 스프라이트·애니메이션의 완성 또는 게임 통합을 뜻하지 않는다. 원본 경로의 `idle`·`confirmed`·`REVIEW` 표기는 별도 동작 규격이나 제작 승인 근거로 사용하지 않는다. 사용자가 구글 드라이브에서 위 로컬 위치로 복사했으며, Codex가 두 파일을 열어 첨부 원화와 시각적으로 일치함을 확인했다. 두 번째 원화의 로컬 파일명은 `energe-sword-grip.png`이며 파일명과 이미지 내용은 변경하지 않았다.

[잠정 승인 보관 목록](../art/warden/provisional-approved/README.md)의 현재 승인 프레임은 캐릭터 135개와 베기 VFX 14개를 합한 149개 PNG다. 전기 보강 v4는 2026-11-11 사용자의 잠정 승인에 따라 프레임·시트를 변경 없이 보관하고 SHA-256 일치를 확인했다. 공격은 2026-11-11 사용자의 잠정 승인 지시에 따라 v5의 7프레임을 변경 없이 복사했고 SHA-256 일치를 확인했다. Run은 사용자가 검토한 [run-review-v4](../art/warden/shading-restore/run-review-v4/review.html)를 변경 없이 복사했으며 이전 Run 32개 PNG와 원화도 보존한다. 잠정 승인 자체는 게임 통합 승인이 아니며 현재 통합 범위는 아래 사용 자산과 별도 개발 요청을 따른다. 걷기·공격에 복원본의 최신 자세를 적용하는 작업은 아직 수행하지 않았다.

측면 파생 이미지는 원화보다 시안 면적이 크고 중간 청색 명암이 줄어들었다. 같은 16색 팔레트를 쓴다는 사실만으로 색조·입체감 일치를 보장하지 않는다. 전류는 한 방향으로 흐르고 천·귀·꼬리는 관성을 표현한다. 기존 코드 애니메이션의 천 물리는 질점·스프링 근사이며 접힘·충돌·지면 마찰을 계산하지 않는다.

## 확정 도구


- Agent Sprite Forge: 캐릭터·프롭·배경·애니메이션 제작과 후처리의 주요 도구.
- pixelfx: VFX 제작의 주요 도구.
- AI 에이전트는 Codex. 외부 생성 서비스와 로컬 도구 사용 자체는 배제하지 않는다. 설치 상태는 새 생성·비용 지출·외부 전송·게임 통합의 승인이 아니다. 설치 위치와 사용 준비는 [도구 구성](tooling.md)을 따른다.


## 리소스 보관 구분

- `art/`: 리소스 생성·원본·후보·확정 제작본을 보관하는 로컬 작업 공간. `.git/info/exclude`의 `/art/`로 Git 추적에서 제외한다. 이 안의 확정본도 게임에 포함된 파일을 뜻하지 않는다.
- `assets/`: 실제 게임에서 사용할 리소스를 복사해 보관하는 폴더. 사용자가 2026-11-08 폴더명을 확정했다. 게임 사용 파일과 필요한 규격·출처 정보를 함께 Git으로 관리한다.
- 사용자 지시에 따른 현재 잠정 승인 범위는 위 목록과 approval.json을 따른다. 과거 폴더 이름에 `approved`가 있다는 이유만으로 현재 승인으로 승계하지 않는다. 기존 자료는 삭제하지 않으며 게임 연결은 별도 승인이다. `art/`의 파일은 Git으로 복원할 수 없으므로 별도 백업이 필요하다.

## 게임에서 사용하는 캐릭터 자산

2026-11-11 사용자 요청에 따라 idle v7·Run v4의 PNG 시트 3장을 `assets/warden/idle.png`, `run_left.png`, `run_right.png`로 복사했다. 이름의 버전을 제거했으며 원본 PNG 바이트와 프레임별 시간·기준점을 보존했다. [게임 자산 출처](../assets/warden/README.md)에 원본 경로·SHA-256을, animations.json에 런타임 규격을 기록한다. .gitattributes는 PNG를 일반 Git 바이너리로 관리한다. 이후 기본 게임플레이 요청으로 공격 v5도 assets/warden/attack.png에 변경 없이 복사해 연결했다. 7프레임·350ms·기준점 (96,120)을 보존하며 왼쪽은 런타임 수평 반전이다. 실제 SDL 첫 프레임·양 방향 출력·발 기준점을 확인했다. 걷기·VFX는 포함하지 않는다. 이 통합 요청은 위 자산의 잠정 승인 상태나 최종 게임 아트 규격을 바꾸지 않는다.
