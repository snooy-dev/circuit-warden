# 아트 기준

## 전체 아트 방향

1차 기획 대비 주인공 캐릭터 디자인을 변경했으며, 게임 전체 아트 스타일은 픽셀 아트로 통일한다. 2026-11-16 사용자가 2차 발표 리뷰에서 명시한 기준이다.

## 작업 방식

반복 스프라이트 생성·보정은 사용자 요청에 따라 직접 제작·검사하고 결과를 채팅으로 보고한다. 별도 specs·계획·체크리스트·검증 보고서를 만들지 않는다. 현재 채택 상태와 장기 기준만 이 문서에 유지한다. 게임 규칙·코드·런타임 통합은 [개발 흐름](workflow.md)을 따른다.

## 오프닝 스토리 컷신

오프닝과 플레이는 전원 구역의 같은 픽셀 격자·팬·구리 케이블·낙뢰를 쓴다. 팬의 움직임과 주변 밝기로 기동·고장을 보여주고, 전선의 스파크에서 워든의 착지점으로 시야를 넓힌다. 상하의 검은 띠는 플레이 카메라가 자리를 잡으면서 걷힌다. [연출 구성](../specs/023-story-intro/plan.md#storyboard).

## 첫 레벨 정비 구역

흡기실의 은청색 팬과 메쉬, 하층의 방열핀, 수직 냉각 샤프트의 연속 지지대, 콘덴서와 필터 코일, 배전실의 퓨즈로 위치를 구분한다. 상부 점검실은 산화된 코인전지와 해어진 리본 케이블, 출력 통로는 노랗게 삭은 다핀 커넥터로 구별한다. 최상부 시험실의 그을린 트랜지스터와 방열핀은 원경으로 눌러 중앙 전투면의 실루엣을 읽을 수 있게 한다.

ImageGen 원화는 논리 픽셀 하나가 월드 두 단위가 되도록 다수결 축소와 제한 팔레트를 적용한다. 개구부에는 원경 배선, 뒤 기둥, 충돌에 맞춘 판재, 가까운 이음쇠를 층별로 조립한다. 판재의 녹과 먼지는 몸체와 이음매에 배치하고 이동면에는 연속된 외곽선을 둔다. 버스바의 주황 전기 아크는 접촉 위험을 표시하고, 복구한 배전 해치의 측면은 청록색으로 바뀐다. [제작 정보](../assets/levels/power-supply/vertical/provenance.json) · [검증](../specs/021-power-supply-level/verification.md#수직으로-엮은-설비와-다음-맵의-관문).

## 기본 적: 금속 먼지 덩어리

2026-11-15 사용자 요청으로 `Circuit_Warden_GameDesign.pptx` 19쪽의 원화를 기본 적 1종의 기준으로 사용한다. 짙은 먼지 몸체, 녹슨 구리 띠와 각진 다리, 작은 금속 구슬을 유지한다. 사용자 후속 지시에 따라 원화 기반 hibit 처리를 적용한다.

정지 디자인 기준은 [metal_dust.png](../assets/enemies/metal_dust.png), 규격·출처·해시는 [metal_dust.json](../assets/enemies/metal_dust.json)에 보관한다. 사용자 후속 요청으로 적의 디테일 수준과 픽셀 크기를 워든에 맞춘다. 원화를 단순화했던55px 자산을 대체해, ImageGen으로 먼지층·구리 녹·금속 구슬을 살린 투명 배경 파생본을 만들고 Agent Sprite Forge의 hibit 다수결 축소·16색 팔레트·1px 외곽선 처리를 적용했다. 128×104 셀, 보이는 높이78px·폭115px, 피벗(64,92), 좌측은 반전이다. 워든과 같은 원본1px=1월드 단위이며 완성 스프라이트를 확대하지 않는다. 이진 알파·팔레트 밖 색0·잘림 없음을 검사하고 실제 SDL에서 크기·접지·양방향 표시를 확인했다. 기존 자산과 [동일 배율 비교](../art/enemies/metal-dust-detail-v2/comparison.png)는 로컬에 보존한다.

사용자의 이동·공격 모션 요청에 따라 로컬 generate2dsprite로 처리·클립 구성·엔진 내보내기를 수행한 [동작 시트](../assets/enemies/metal_dust_motion.png)와 [클립 설정](../assets/enemies/animations.json)을 게임에 적용했다. 원본 리깅의 큰 보행 변형은 다리 왜곡으로 채택하지 않았고, 사용자 지시대로 내장 ImageGen의 이동·공격 포즈로 전환했다. 원본을 소폭 움직인 중간 포즈2장을 함께 쓴다. 영상 생성은 사용하지 않았다.

이동은8프레임·600ms 반복, 공격은 예고3프레임·450ms, 돌진1포즈·280ms, 회복3프레임·600ms다. 공통160×112 셀·피벗(80,100)이며 기존 idle 픽셀을(16,8) 위치에 그대로 넣어 크기·접지를 보존했다. 모든 포즈는 기존16색 팔레트·이진 알파·원본1px=1월드 단위를 유지한다. 두 구리띠·금속 구슬·먼지 몸체·뾰족한 머리를 비교했고 잘림·팔레트 밖 색0을 확인했다. 이동 원본 축소율2.882는 스킬 권장 하한4에 미달해 경고를 유지한다. 생성 포즈 간 작은 질감 변화와 공격의 적은 키포즈 수는 한계다. [동작 미리보기](../art/enemies/motion-v1/motion-preview.gif)·[출처와 QA](../assets/enemies/metal_dust_motion.json)에 근거를 남긴다. 최종 미술 판단은 사용자 확인 전이며 원화·미채택 리깅·생성본은 로컬 `art/enemies/`에 보존한다.

## 전원 구역의 새 몬스터

냉각 팬 비행체는 깨진 은청색 하우징, 세 날, 주황 회전축, 구리 단자로 공중의 방향을 읽게 한다. 누전 콘덴서는 자주색 원통, 밝은 극성 띠, 십자 벤트와 두 단자 발로 세로 실루엣을 만들고 방전 전에는 틈과 지면 범위가 밝아진다. 팬의 회전 포즈와 콘덴서의 팽창은 각자 하나의 ImageGen 원화에서 가공했다.

최종 몸체의 보이는 크기는 팬 64×40, 콘덴서 48×68 월드 단위이며 전원 구역과 같은 2×2 논리 픽셀을 쓴다. 방전은 pixelfx의 `lightning/thunderclap`에서 가져온 프레임을 앰버 팔레트로 가공했다. 원화·프롬프트·색상표·MIT 표기는 [제작 자료](../assets/enemies/field-source/), 런타임 크기와 시간은 [클립 설정](../assets/enemies/field-enemies.json), 가공 및 해시는 [출처](../assets/enemies/field-enemies.provenance.json)에 있다.

## 전원 조립체 보스

GameDesign 20쪽의 기울어진 청록 콘덴서, 갈라진 십자 벤트, 구리 코일, 두꺼운 두 케이블과 단자 끝을 유지한다. 내장 ImageGen 원화를 hi-bit로 가공한 기본 실루엣은 204×138 월드 단위다. 부하 시험실의 어두운 원경에서는 은색 벤트와 코일이 윤곽을 잡는다. 팔을 접는 자세와 코일 채도 변화, 붉은 착지 표지가 각 피해 범위를 예고한다.

원화에 등록한 15개 몸체 셀과 4개 전기탄 셀을 2×2 격자로 재생한다. 전기탄과 착지 전류는 pixelfx의 `lightning/ball-lightning`과 `lightning/thunderclap`에서 가져왔다. [원화·프롬프트](../assets/enemies/boss-source/) · [출처와 해시](../assets/enemies/power-assembly.provenance.json) · [MIT 표기](../assets/enemies/field-source/pixelfx-CREDITS.txt).

## 워든 원화 기준

캐릭터의 정체성과 무기 용도는 [게임 설계](game-design.md#주인공-워든warden)가 소유한다. **제작 시 고정 디자인은 이 절의 수치·형태·명암·변형 규칙을 사용한다.** 아래 원화 파일은 측정 출처와 시각 대조용이다. 파일 이름이나 새 생성 결과를 보고 매번 다른 디자인을 추론하지 않는다. 동작의 궤적·자세·시간은 [동작별 적용 범위](#동작별-적용-범위)에서 따로 정한다.

### 파일 없이 적용하는 외형 요약

워든은 **큰 둥근 머리, 위쪽의 둥근 귀 두 개, 검은 세로 타원 눈 두 개, 짧고 둥근 팔과 두 다리, 넓은 물방울형 꼬리**를 가진 청색 전기 생명체다. 코·입·주둥이·눈동자·흰자는 보이지 않는다. **손발은 분절 없는 단순한 둥근 덩어리이며 모든 자세에서 손가락·발가락 형태가 없다.** 검을 쥐거나 착지할 때도 손가락·발가락을 새로 만들지 않는다. 몸통과 골반은 한 덩어리이며 낮은 위치에서 두 다리로 갈라진다. 허리띠 같은 분리선이나 둥근 골반에 별도 발을 붙인 구조를 만들지 않는다.

현재 제작 시점은 오른쪽을 보는 측면에 가까운 시점이다. 머리는 약간 관찰자를 향해 **가까운 눈은 넓게, 먼 눈은 얼굴 오른쪽 끝에 가늘게** 보인다. 완전 옆얼굴의 한 눈이나 정면의 같은 폭 눈 두 개로 바꾸지 않는다. 목의 겹친 띠와 짧은 어깨 덮개가 신체 윗부분을 가리고, 긴 천 자락은 뒤쪽 위, 꼬리는 뒤쪽 아래로 별개로 뻗는다.

머리 폭을 **W=1**로 놓으면 현재 측면 원화의 귀 포함 전체 높이는 약 **2.22W**, 귀를 뺀 보이는 머리 높이는 **0.89W**, 가까운 눈은 **0.26W×0.37W**, 천 아래 보이는 팔은 약 **0.16W×0.19W**, 천 중앙 밑단부터 발끝까지 보이는 하체는 약 **0.62W**다. 이는 아래에서 정의한 같은 자세의 화면상 비율이다. 가려진 관절 길이나 회전한 자세의 외곽 상자 크기로 바꾸어 해석하지 않는다.

### 측정 기준과 신체 부위별 비율

2026-11-16 기본 원화와 현재 측면 제작 원화의 원본1254×1254에서 측정했다. **기본 원화는 정면에 가까운 외형 근거, 측면 값은 현재 게임 시점의 제작 기준**이다. 두 열을 섞거나 평균내지 않는다. 단위는 원화px이고 좌표는 좌상단(0,0), 오른쪽·아래 끝 제외다.

- 기준 머리 폭 W: 기본 원화 y=490의 x=403~893, **490px**. 측면 원화 y=540의 x=514~936, **422px**. 귀·천을 제외한 볼 높이의 단면이다. 비율은 해당 길이÷W이며 소수 둘째 자리로 반올림했다.
- 자동 실측: 기본 원화에서 분홍 배경(R>180, B>180, G<100)을 제외하고, 측면에서는 알파≥128인 픽셀을 사용했다. 눈은 머리 영역의 RGB 각 채널<60인 연결 영역이다. 게임 픽셀 비교에는 별도의 완성 idle 기준을 사용한다.
- **약** 표시는 겹침 경계를 사람이 선택한 값이다. 아래 좌표는 재측정 위치를 명시하며 해부학적 경계나 측정 오차의 상한을 보증하지 않는다. 수동 판독 오차를 신체 신축 허용량으로 사용하지 않는다.

**얼굴 배치:** 기준 좌표를 기본 원화(403,270), 측면 원화(514,336)으로 잡고 `(점−기준 좌표)/W`로 나타내면, 기본 원화 눈 중심은 (0.31,0.45)·(0.74,0.44), 현재 측면 눈 중심은 (0.69,0.49)·(0.96,0.48)이다. 가까운 눈은 머리의 앞쪽 절반에 놓이며 먼 눈은 얼굴 끝에 붙는다. 머리가 기울 때 이 상대 배치도 머리와 함께 회전한다.

**가림의 한계:** 망토 속 어깨, 팔꿈치·손목, 골반 관절·무릎은 원화에서 분리해 볼 수 없다. 표의 노출 팔 길이를 상완+전완 길이로 쓰거나, 홈 아래 길이를 허벅지+종아리 길이로 쓰지 않는다. 기본 원화보다 측면의 홈 아래 구간이 짧다는 이유로 다리를 새로 줄이지 않는다. 이 자료는 같은 시점의 가시 비율 규격이며 숨은 골격 치수·정면/측면을 연결하는 3D 모델 시트는 아니다.

### 형태와 연결 구조

- **머리:** 볼과 턱이 이어지는 넓은 둥근 타원이다. 주둥이 돌출·뾰족한 턱·눈썹·입선을 추가하지 않는다. 아래는 목도리에 일부 가려지고, 귀는 머리 윗부분과 매끄럽게 이어진다. 머리를 사람 두상처럼 작은 구와 긴 턱으로 나누지 않는다.
- **귀:** 끝이 둥근 두꺼운 잎 또는 캡슐 모양 두 개다. 끝을 뾰족하게 만들거나 가늘고 긴 토끼 귀로 늘리지 않는다. 현재 시점에서는 귀가 겹치며 가까운 귀가 먼 귀 일부를 가린다. 귀 내부의 흰 곡선은 전류이며 구멍·분홍 안쪽 귀가 아니다.
- **눈:** 검은 세로 타원이다. 흰자·동공·반짝이는 흰 점·테두리 링을 추가하지 않는다. 먼 눈의 가느다란 노출을 가까운 눈과 같은 폭으로 키우지 않는다.
- **몸통·골반·다리:** 천 아래에서 하나의 매끄러운 둥근 몸이 내려오고, 낮은 U자 홈으로 두 발이 나뉜다. 복부와 골반을 분리하는 수평선·갑옷 판·허리띠가 없다. 발은 다리 끝의 매끄럽고 둥근 덩어리이며 발가락 돌기·갈라진 선·발톱이 없다. 발등·발목·신발 굽을 새로 만들지 않고, 이동·점프·착지·공격에서도 이 단순한 끝모양을 유지한다. 꼬리와 다리 사이의 음영·빈 공간을 유지한다.
- **팔·손:** 천 아래에 짧고 둥근 물방울형 팔이 보인다. 천에 가려진 어깨에서 자연스럽게 이어지고 별도 어깨 공이나 튀어나온 팔꿈치를 추가하지 않는다. 손은 팔 끝의 단순한 둥근 형태이며 **모든 자세에서 손가락 분절·엄지 돌기·손톱·주먹 마디가 없다.** 검을 잡을 때도 손가락을 자루에 감은 인간형 손을 생성하지 않는다. 같은 둥근 손과 자루의 접촉·겹침으로 잡고 있음을 표현하며 해부학적 오른손과 어깨→팔→손→자루의 연결을 유지한다.
- **천:** 목을 감싼 겹친 띠, 어깨·윗몸을 덮는 짧은 천, 뒤로 늘어진 긴 자락으로 읽힌다. 목 띠의 밝은 윗단과 어두운 겹침이 층을 나눈다. 어깨 덮개는 복부 위를 가리고, 긴 자락은 꼬리보다 높은 곳에서 시작한다. 별도 허리 망토나 새 천 조각을 붙이지 않는다.
- **꼬리:** 뒤쪽 아래로 이어진 넓고 납작한 물방울형이다. 뿌리보다 바깥 부분이 부풀고 끝은 둥글다. 가는 밧줄·뾰족한 도마뱀 꼬리·세 번째 다리로 바꾸지 않는다. 천 자락과 구별되는 별도 형태이며 동작에 따른 겹침은 허용한다.

### 색과 명암 규격

몸과 천의 주색은 **중간 청색**, 밝은 면은 청록, 깊은 면은 남색이다. 원화에는 부드러운 변화가 있지만 게임 표현은 아래16색의 픽셀 면으로 제한한다. 새 파생본의 색감은 이 규격을 바꾸는 근거가 아니다.

| 역할 | 게임 색상 전체 목록 | 배치 |
|---|---|---|
| 눈·최암부·깊은 그림자 | #020816, #00193E, #002B64, #003E8B | 눈은 거의 단색. 머리 아래, 천 겹침 아래, 몸·꼬리의 오른쪽/아래 깊은 면. 검은 선으로 복부를 분할하지 않음 |
| 넓은 중간톤 | #0050B1, #0064CA, #007BDB, #0091E5, #00ABEA | 이마·볼·복부·천·꼬리의 대부분을 차지하는 청색 면. 이 면을 넓은 청록·흰색으로 대체하지 않음 |
| 청록 하이라이트 | #00C3ED, #00DAF2, #19EFF6, #5BF7F9 | 귀·머리의 좌상단 곡면, 천의 윗단·접힌 가장자리, 팔과 꼬리의 위쪽 가장자리를 따라 좁게 배치 |
| 가장 밝은 전류·일부 하이라이트 | #A3FDFD, #DCFFFF, #FFFFFF | 가늘고 끝이 뾰족한 전류와 작은 밝은 부분. 큰 흰 면·눈의 흰 반사점·전신 발광 테두리로 확대하지 않음 |

현재 오른쪽 idle 0번의 불투명2864픽셀은 깊은 영역685(23.9%), 중간톤1689(59.0%), 청록 하이라이트403(14.1%), 가장 밝은3색87(3.0%)이다. **한 자세·한 전류 위상의 관찰값**이며 모든 자세에 동일 비율을 강제하는 합격 기준은 아니다. 색 목록이 같아도 중간톤이 사라지고 청록 면이 커지면 명암 불일치다.

- **광원과 입체감:** 오른쪽 기준으로 좌상단이 가장 밝고, 오른쪽·아래로 갈수록 청색→남색으로 어두워진다. 이마의 밝은 띠 아래에 넓은 청색 볼과 어두운 하단이 남아 둥근 부피를 보여야 한다. 전류를 제외한 조명은 프레임마다 반대 방향으로 바뀌거나 점멸하지 않는다.
- **천과 신체의 겹침:** 머리 아래·목 띠 아래·어깨 천 아래에는 좁고 어두운 접촉 그림자가 있다. 천의 밝은 테두리는 반사광이고 몸의 전류와 별개다. 이 접촉 그림자를 복부의 새 허리 경계로 연장하지 않는다.
- **전류:** 몸의 밝은 청록~흰 곡선은 **전기로 이루어진 신체 안에 전류가 흐르는 모습을 보여주는 필수 디테일**이다. 2026-11-17 사용자 보충에 따라 원화의 선은 전류가 흐르는 한순간이며, 신체에 고정된 무늬나 고정 경로가 아니다. 두 귀·얼굴·몸통·꼬리 안에서 전류선의 위치·길이·굽음이 연속적으로 변하고 생성·이동·소멸한다. 밝은 머리와 청록 잔상은 이 이동을 드러내며, 순백색으로 일괄 변경하지 않는다. 고정된 선의 밝기 변화·전체 점멸·외부 스파크만으로 흐름을 대체하지 않는다. 신체 굴곡과 가림을 따르고 프레임마다 무관한 위치로 튀는 변화는 피한다. 원치 않는 잔여 픽셀을 지울 때 의도된 전류까지 제거하지 않으며, 천의 반사광을 신체 전류로 만들지 않는다.
- **픽셀 경계:** 최종 캐릭터는16색·이진 알파, 같은 게임 크기의 픽셀 밀도를 유지한다. 깊은 남색의 얇은 경계와 명암 면으로 읽히게 하고 두꺼운 검은 테두리·흐린 반투명 얼룩을 추가하지 않는다. 기존 지상 공격 v6의 지정 외곽선은 #020816·1px다. idle 전체 외곽이 모두 이 색이라는 뜻은 아니다.
- **좌측:** 현재 게임의 좌측은 조명까지 수평 반전하는 자산 방식이다. 위 광원 설명은 오른쪽 기준이며, 별도 좌측 조명을 재설계하라는 지시가 아니다.

기존 채택 측면 제작의 전류 방향은 다음과 같다. 방향은 화면 좌우가 아닌 **캐릭터의 부위 기준**이다. 이는 기존 자산의 기록이며, 2026-11-17 이후 새 제작에서 원화의 경로·좌표를 고정하라는 제약이 아니다. 새 전류선은 위 사용자 보충에 따라 연속적으로 이동·변형한다.

| 전류 경로 | 진행 방향 |
|---|---|
| 가까운 귀·먼 귀 | 각 귀 끝 → 머리와 이어지는 뿌리 |
| 이마 | 머리 뒤쪽 → 얼굴 앞쪽 |
| 아래 얼굴 | 얼굴 앞쪽 → 뒤쪽 |
| 몸통 | 위쪽 앞면 → 아래쪽 뒷면 |
| 꼬리 | 몸에 붙은 뿌리 → 꼬리 끝 |

### 검의 형태 비율

검은 가는 에너지 손잡이, 양옆이 불꽃처럼 벌어지는 기부, 길고 가늘게 뾰족해지는 칼날로 이어진다. 실체 내부의 흰 중심 전류가 청록색 면을 따라 뻗고 가지가 갈라진다. 금속 날·가드·둥근 손잡이 장식·두꺼운 장검으로 바꾸지 않는다.

검 원화1536×1024에서 손잡이 끝(355,941)→검끝(1386,79)의 축 길이를 **L≈1344px**로 잡았다. 발광 번짐을 제외하기 위해 알파≥200 및 G·B≥180인 영역을 축에 수직으로 측정했다. 축 위 위치는 손잡이 끝0, 검끝1이며 각 위치±0.002L 띠 안의 폭이다.

|---|---|---|
| 0.10L | 약70px | **0.052L**, 손잡이 쪽 가는 구간 |
| 0.30L | 약193px | **0.143L**, 넓은 불꽃형 기부 구간 |
| 0.60L | 약122px | **0.091L**, 길게 좁아지는 칼날 |

단독 검 원화에는 워든이 없어 **검 길이 L과 머리 폭 W의 상대값은 이 원화에서 측정할 수 없다.** 임의로 두 파일의 픽셀 수를 나누지 않는다. 동작 제작 시 선택한 L/W는 원근 적용 전 클립의 제작 설정으로 명시하고 프레임 전체에서 고정한다. 화면상 투영 길이는 동작별 원근 허용 범위를 따른다. 검 원화의 내부 비율은 유지하며, 이전 후보의63.70px 같은 값을 전체 워든의 확정 검 길이로 승격하지 않는다.

### 게임 크기로 비교하는 기준

고해상도 측면 제작 설정은 전경 높이938px→80px, 기준점(735,1126)→게임 셀(64,92)이다. 이 배율에서 W422는 약36px다. 최종 픽셀은 축소·외곽 처리의 결과이므로 원화 비율에 단순 반올림한 값만으로 합격시키지 않는다.

동작별 중립 자세와 주요 자세를 같은 배율에서 대조한다. 머리와 두 눈의 상대 배치, 둥근 손발, 몸통과 골반의 연결, 천·꼬리의 부착점, 중간 청색 면과 내부 전류를 확인한다. 아래 베기처럼 몸이 화면을 향해 돌아올 때는 시점에 따라 먼 눈의 노출 폭이 커진다. 발 피벗과 화면상 몸 중심을 맞춘 뒤 실제 재생에서 발의 접촉과 자세 전환을 확인한다. [캐릭터 모델 시트 기준](https://learn.toonboom.com/modules/character-design1/topic/character-model-sheets1).

주요 자세마다 행동의 목적이 전신 실루엣에서 읽혀야 한다. 달리기는 발 디딤과 골반 위 체중 이동, 점프는 발구름·상승·접지, 검격은 준비·접촉·회수에 맞춰 몸통과 팔다리가 함께 움직인다. 천과 꼬리는 몸에 붙은 채 뒤따르고, 짧은 타격 정지는 접촉 자세를 읽히게 한다. [게임 애니메이션의 주요 자세와 시간](https://gdcvault.com/play/1021656/Powerful-and-Effective-Animation-for).

현재 idle 오른쪽0번의 셀은128×104, 알파>0인 전체 범위는(20,11)~(82,93), 폭62·높이82px이며 가까운 눈은(65,36)~(75,49), **10×13px**다. 귀·천·꼬리·외곽선이 포함된 전체 범위를 순수 신체나 다른 자세의 목표 크기로 쓰지 않는다. 원본1px=1월드 단위를 유지하며 공격 셀이192×192여도 캐릭터만 크게 확대하지 않는다. 이 값은 망토 바람 v2의 비교 자세에서 얻었다. 현재 게임 대기 시트는 같은 기준점과 팔레트를 사용한다.

### 제작과 일관성 검수

1. 제작의 고정 지시에 이 절의 **측면 비율·형태·명암·허용 변형**을 명시하고 동작별 목표를 따로 붙인다. 원화 파일은 보조 참조이며 문서 규격을 대신하지 않는다. 공중 공격에서 금지된 이전 공격 원화·파생 포즈·프레임·영상은 입력하지 않는다. 반려본을 새 신체 기준으로 삼지 않는다.
2. 새 주요 자세(공격의 시작·타격·종료 등)를 수치와 형태 설명에 대조한다. 머리·눈·하체·팔·그립·검 형태가 어긋나면 해당 자세를 수정한 뒤 모션으로 확장한다. 새 후보만으로 원화 승인 상태를 부여하지 않으며, 사용자가 특정 원화의 승인 전 모션 생성을 보류했다면 그 지시를 유지한다.
3. 같은 고정 배율에서 전체 프레임을 비교한다. 머리 좌표계의 얼굴 배치, 몸통/골반 윤곽, 팔과 검 연결, 다리 홈과 둥근 발, 천과 꼬리의 분리를 본다. **손가락·발가락·엄지 돌기·분절선이 생기지 않았는지 검 그립과 착지를 포함한 모든 자세에서 확인한다.** 얼굴 정렬 비교와 실제 동작 위치 비교를 함께 보고 프레임별 재배율로 신축을 숨기지 않는다. 가려진 관절은 미확인으로 남긴다.
4. 원본 게임 크기·정수배 확대·정상 속도·느린 재생에서 각각 읽힘, 윤곽, 전신 연동, 인접 프레임 연결을 확인한다. 양다리·망토 연결부와 무장 동작의 손목·검 기부를 전체 프레임에서 본다. **전류선의 위치·길이·굽음이 연속적으로 변하며 밝은 머리와 청록 잔상이 실제 이동·생성·소멸하는지 재생에서 확인한다.** 한 장의 밝은 무늬나 고정 경로의 밝기 변화만으로 흐름을 통과시키지 않고, 몸통·귀·얼굴·꼬리의 디테일 누락도 확인한다. 현재 공중 공격에서는 준비→타격→반동 순서도 확인한다.
5. **파일 규격 / 디자인 일관성 / 동작 연결**을 구분해 채팅과 기존 제작 메타데이터에 남긴다. 팔레트·알파·잘림·패키지 검사는 파일 규격의 근거다. 디자인 오류나 동작 미확인을 자동 검사 통과로 덮지 않는다. 별도 검증 문서는 만들지 않는다.

## 동작별 적용 범위

### 현재 공중 공격

공중 아래 베기는 측면에서 준비한 뒤 정면에서 발밑을 가로지르는 전용 10프레임이다. 오른쪽을 향해 시작할 때 검 끝은 화면 오른쪽 낮은 위치에서 발밑 중앙을 지나 왼쪽으로 빠진다. 적중 정지에는 원호를 끝까지 지난 자세를 사용한다. 지상 검격의 pixelfx 층을 아래로 돌려 검이 지나간 방향에 흰 중심광과 갈라진 방전을 남긴다. [자산 출처](../assets/warden/downstrike-source/provenance.json).

공중 일반 검격은 허리 뒤의 낮은 자세에서 시작한다. 어깨와 팔꿈치가 돌아오면서 검 끝이 앞쪽 위에서 수평 구간을 짧게 지나 아래쪽으로 빠진다. 전개 구간에는 기존 검 원화를 사용한다. 팔을 접을 때 검이 짧아지고 몸을 세워 공중 자세로 돌아온다.

두 모션은 워든 원화의 관절을 기준으로 윗팔과 아래팔의 각도를 프레임마다 지정한다. 검 손잡이의 기준점을 같은 손에 고정하고, 회수할 때까지 팔꿈치와 손의 경로가 이어지게 한다. 낙하·착지와 아래 베기 적중 반동은 [기본 게임플레이](systems/basic-gameplay.md#공중-공격)를 따른다.

### 기존 지상 공격 v5/v6 전용

이전 게임 공격 v5/v6의 자세 기준이다. 현재 교체 대상인 승인 HK v6·팔 보정 v3의 자세 기준으로 확대하지 않는다. 오른쪽을 볼 때 검끝이 위→몸 앞→아래→왼편으로 지나가고 손의 이동과 앞다리 체중 이동이 함께 나타난다. 후반에는 검팔 자체가 골반을 지나 몸 뒤로 넘어간다. 손을 앞에 고정하고 검만 돌리는 동작은 제외한다.

4~6번에서 오른팔을 더 들어 팔·검의 원근으로 보이는 길이를 줄이고,7번은 오른팔을 들어 검을 왼쪽 위 대각선으로 향하게 한다. 진행 방향을 더 바라보는 수직축 약20도 회전도 이 기존 지상 공격의 지시다. 화면 평면 회전이나 공중 공격의 공통 지시로 사용하지 않는다. 이7프레임 클립은 전신 베기 구간만 포함하고 별도 준비·회수·종료 대기는 제외한다. 복부를 골반과 별도 판처럼 나누는 경계는 없애되 흰 전류와 망토의 접촉 그림자는 보존한다. 검 출현 VFX는 보류 상태다.

### idle·Run·점프·대시

idle은 비무장이다. 각 동작의 채택본·연결 프레임·제작 규격은 아래 표를 따르며 지상 공격의 궤적이나 공중 공격의 준비/반동을 적용하지 않는다. 게임의 재생 시간과 행동 잠금은 [기본 게임플레이](systems/basic-gameplay.md)가 소유한다.

2026-11-17 사용자 피드백에 따라 idle은 머리·몸통 자체의 작은 호흡·체중 이동이 보여야 한다. 꼬리·천의 큰 흔들림이나 전류 변화만으로 신체의 idle 동작을 대신하지 않는다. 꼬리와 천은 몸의 작은 움직임에 잔잔하게 뒤따르며, 전류가 액체처럼 미끄러지는 표현은 재작업 대상이다. 구체적인 진폭·방전 시간은 후보 조정값이며 채택 기준으로 확정하지 않는다.

Run은 사용자가 검토한 [run-review-v4](../art/warden/shading-restore/run-review-v4/review.html)를 변경 없이 복사했으며 이전 Run 32개 PNG와 원화도 보존한다. 잠정 승인 자체는 게임 통합 승인이 아니며 현재 통합 범위는 아래 사용 자산과 별도 개발 요청을 따른다. 걷기·공격에 복원본의 최신 자세를 적용하는 작업은 아직 수행하지 않았다.

일부 측면 파생본의 시안 면적 증가·중간 청색 감소는 알려진 불일치이며 새 색감 기준으로 삼지 않는다. 비교 방법은 위 공통 기준과 검수 절차를 따른다. 기존 코드 애니메이션의 천 물리는 질점·스프링 근사이며 접힘·충돌·지면 마찰을 계산하지 않는다.

## 리소스 보관 구분

- `art/`: 리소스 생성·원본·후보·확정 제작본을 보관하는 로컬 작업 공간. `.git/info/exclude`의 `/art/`로 Git 추적에서 제외한다. 이 안의 확정본도 게임에 포함된 파일을 뜻하지 않는다.
- `assets/`: 실제 게임에서 사용할 리소스를 복사해 보관하는 폴더. 사용자가 2026-11-08 폴더명을 확정했다. 게임 사용 파일과 필요한 규격·출처 정보를 함께 Git으로 관리한다.
- 사용자 지시에 따른 현재 잠정 승인 범위는 위 목록과 approval.json을 따른다. 과거 폴더 이름에 `approved`가 있다는 이유만으로 현재 승인으로 승계하지 않는다. 기존 자료는 삭제하지 않으며 게임 연결은 별도 승인이다. `art/`의 파일은 Git으로 복원할 수 없으므로 별도 백업이 필요하다.

## 전하 런타임 자산

2026-11-15 기존 확정 전하 상태 v5·반전 v2를 assets/charge에 보관하고 이번 구현 요청으로 연결했다. inactive/active는 각72프레임·80×80·24fps·3초이며 pulse는10프레임이다. transition.json의 출처 SHA-256을 보존한다. 공유 위상과 값·속도 연속 반전을 유지한다. 사용자 PNG 성능 개선 요청으로 색/알파 보간·파동 합성은 제작 단계에서33단계×72위상으로 구워 assets/charge/baked에서 선택 재생한다. 안정 상태 원본 RGBA는 보존하지만 출력 배율의 샘플링까지 픽셀 일치를 보장하지는 않는다. 중간 상태의 단계화와 최대1px bob 차이는 허용된 미세 차이이며 원본은 보존한다.
