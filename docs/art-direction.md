# 아트 기준

상태: **제작 도구 확정 / 스타일·규격 미정 / 제작 미시작**

## 확정 도구

- Agent Sprite Forge: 캐릭터·프롭·배경·애니메이션 제작과 후처리의 주요 도구.
- pixelfx: VFX 제작의 주요 도구.
- AI 에이전트는 Codex. 외부 생성 서비스와 로컬 도구 사용 자체는 배제하지 않는다.

## 미정 사항

손그림·픽셀 등의 스타일, 팔레트, 게임 표시 크기, 방향 수, 프레임·시간·기준점, 배경 레이어와 효과 강도. pixelfx 설치가 게임 전체의 픽셀 스타일 확정을 뜻하지 않는다.

## 제작 시 기록

기능 작업에 에셋 용도·게임 상태·기준 이미지·출력 규격·원본/가공 경로·사용 도구/서비스·검수 결과·출처와 필요한 표시를 기록한다. 출력이 Pico2D에 바로 연결된다고 가정하지 않는다. 공격 판정 등 게임 규칙을 아트 도구가 바꾸지 않는다.

현재는 설치만 승인되었다. 생성 서비스 호출·비용 지출·게임용 에셋 생성은 하지 않는다.

## 명암·비율 복원 검토

[009 복원](../specs/009-warden-shading-restore/spec.md)은 원화의 청색 중간 명암 복원과 추가 발·몸/머리 방향 수정이다. 기존 잠정 승인본은 유지한다. 최신 proportion-fix-v1은 가까운 귀·팔을 줄인 정지 검토 후보로 [비율 검사](../specs/009-warden-shading-restore/proportion-verification.md)를 마쳤으며 아직 동작에 적용하지 않았다.
