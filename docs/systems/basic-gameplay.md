# 기본 게임플레이

상태: 2026-11-11 사용자 요청에 따른 초기 조작 구현·검증 완료. 기술 가정은 최종 게임 수치 승인이 아니다.

## 규칙과 소유 범위

- 플레이 레벨은 GameplayMode를 사용한다. 타이틀 등 다른 규칙의 레벨은 향후 별도 모드를 지정한다.
- Warden은 A/D로 수평 이동한다. 양쪽 동시 입력은 정지하고 하나를 놓으면 남은 방향으로 이동한다.
- 왼쪽 클릭은 현재 바라보는 방향으로 공격 1회다. 공격 중 정지·방향 고정, 추가 클릭 무시, 종료 후 현재 유지 중인 A/D를 반영한다. 커서 조준·버튼 유지 자동 공격은 없다.
- 이동 중 Run, 정지 중 idle, 공격 중 단발 공격을 재생한다. 피해·적·충돌·콤보는 제외한다. 후속 요청으로 베기 VFX 표시를 포함한다.

## 상태 전이·경계 조건

idle ↔ run은 실제 이동 여부로 결정한다. idle/run → attack은 왼쪽 클릭, attack → idle/run은 재생 완료와 현재 이동 입력으로 결정한다.
포커스 상실·최소화는 유지 키와 미시작 공격을 지운다. 시작한 공격은 계속 끝낸다. 무효 출력에서는 새 공격을 시작하지 않는다. 창 축소의 경계 보정은 공격 중에도 적용한다.

## 기술 가정·검증

기존 속도·배율·바닥선·경계는 [기술 구조](../architecture.md)를 따른다. 방향키 별칭은 A/D로 대체한다. 공격 시간은 [아트 기준](../art-direction.md)의 원본을 사용한다. 왼쪽 공격은 기존 시트를 수평 반전한다.
입력 중복·공격 중 키 변경·재클릭·첫 프레임·종료는 선택한 자동 검사로, 크기·접지·좌우 재생은 SDL 창으로 확인한다. 근거는 [011 검증](../../specs/011-basic-gameplay/verification.md)에 둔다. 최종 플레이 감각·미술 품질은 사용자 직접 확인 전이다.

베기 효과는 공격 시작 위치·방향에 생성하고 캐릭터 뒤에서 원본 700ms 동안 재생한다. 캐릭터의 350ms 공격 종료 후에도 잔여 효과는 남아 소멸한다. 새 공격은 별도 효과를 생성하며 기존 효과를 재시작하지 않는다. 피해 판정은 없다.

## 점프

2026-11-13 사용자 요청으로 제자리·달리기 점프를 구현했다. 키는 Space를 기술 기본값으로 사용한다. 높이는 캐릭터 키의 3배이며 기준 키는 idle의 투명 여백 제외 최대 높이(귀 포함)다. 수치·측정은 [기술 구조](../architecture.md)를 따른다. 공중에서도 A/D를 조작하며 수평 이동 중 Run, 정지 중 idle을 재생한다.

지상에서 새 Space 입력만 점프한다. 공중 재점프·버튼 유지 자동 점프·착지 입력 예약·공중 공격은 없다. 지상 공격 중 Space는 무시한다. 같은 갱신의 점프/공격 요청은 점프를 우선한다. 포커스 상실/최소화는 유지 키·미시작 요청을 지우되 진행 중 점프는 끝까지 착지한다. 무효 출력에서는 새 점프를 시작하지 않는다. 플랫폼·충돌·새 모션은 제외한다. 상승 0.4초·총 체공 약 0.8초는 기술 기본안이며 사용자 체감은 추후 확인한다.
