# 기본 게임플레이

상태: 2026-11-11 사용자 요청에 따른 초기 조작 구현·검증 완료. 기술 가정은 최종 게임 수치 승인이 아니다.

## 규칙과 소유 범위

- 플레이 레벨은 GameplayMode를 사용한다. 타이틀 등 다른 규칙의 레벨은 향후 별도 모드를 지정한다.
- Warden은 A/D로 수평 이동한다. 양쪽 동시 입력은 정지하고 하나를 놓으면 남은 방향으로 이동한다.
- 활성 전하 왼쪽 클릭은 [순간이동](charge-teleport.md)이 우선한다. 그 외 왼쪽 클릭은 현재 바라보는 방향으로 지상 또는 공중 공격 1회다. 공격 중 수평 이동·방향 전환을 잠그고 추가 클릭은100ms 선입력으로 처리한다. 종료 후 현재 유지 중인 A/D를 반영한다. 커서 조준·버튼 유지 자동 공격은 없다.
- 이동 중 Run, 정지 중 idle, 공격 중 단발 공격을 재생한다. 기본 적과 피해 판정은 [기본 적 전투](basic-enemy.md)를 따른다. 콤보는 포함하지 않는다.

전하 순간이동은 공격·점프·대시의 잠금 예외로 현재 동작과 선입력을 즉시 취소한다. 도착·낙하 규칙은 [전하 순간이동](charge-teleport.md)을 따른다.

## 상태 전이·경계 조건

idle ↔ run은 실제 이동 여부로 결정한다. idle/run → attack은 왼쪽 클릭, attack → idle/run은 재생 완료와 현재 이동 입력으로 결정한다.
포커스 상실·최소화는 유지 키와 미시작 공격을 지운다. 시작한 공격은 계속 끝낸다. 무효 출력에서는 새 공격을 시작하지 않는다. 창 축소의 경계 보정은 공격 중에도 적용한다.

## 기술 가정·검증

기존 속도·배율·바닥선·경계는 [기술 구조](../architecture.md)를 따른다. 방향키 별칭은 A/D로 대체한다. 지상 공격은 HK v6·팔 보정 v3와 승인 FX v11을 합성한340ms 시트, 공중 공격은 승인 v9·눈색/전류 v4의300ms 시트를 사용한다. 왼쪽 공격은 해당 시트를 수평 반전한다. 자산 출처는 [아트 기준](../art-direction.md#게임에서-사용하는-캐릭터-자산)을 따른다.
입력 중복·공격 중 키 변경·재클릭·첫 프레임·종료는 선택한 자동 검사로, 크기·접지·좌우 재생은 SDL 창으로 확인한다. 근거는 [011 검증](../../specs/011-basic-gameplay/verification.md)에 둔다. 최종 플레이 감각·미술 품질은 사용자 직접 확인 전이다.

지상 베기 효과는 공격 40ms부터 보이며 모션과 같은 클립에서 재생한다. 모션이 끝나거나 취소되면 효과도 함께 끝난다. 효과 자체의 피해 판정은 없다. 공중 공격은 승인 캐릭터 모션만 재생한다.

### 공중 공격

2026-11-18 사용자 요청으로 상승/낙하 중 왼쪽 클릭 공격을 추가한다. 점프 시작·착지·대시의 잠금과 마지막 행동1개/100ms 선입력, 전하 클릭 우선순위는 유지한다. 공중 공격 중 수직 운동은 기존 점프의 중력·속도를 계속 적용하며 강제 급강하·상승 반동·체공 정지나 추가 점프를 만들지 않는다. 반동은 모션의 표현이다.

공격이 끝났을 때 공중이면 실제 상승/낙하 단계의 점프 모션으로 돌아간다. 공격 도중 바닥에 닿으면 공격 모션과 남은 타격을 즉시 끝내고 기존 착지180ms 모션·잠금을 시작한다. 착지 시 공중 대시 사용 제한과 마지막 전하 제외를 기존대로 회복한다. 피해·활성 시간·공격당1회 규칙은 지상과 동일하며 [기본 적 전투](basic-enemy.md)가 소유한다. 점프 궤적·방향 잠금·착지 경계의 시간 분할을 검사한다. 구현·검증 상태는 [진행 상태](../progress.md)와 [011 검증](../../specs/011-basic-gameplay/verification.md)을 따른다.

## 점프

Space를 새로 누르면 시작120ms 후 이륙한다. 높이는 기존 idle 기준 키83의2배인166 월드 단위이며 상승400ms·하강400ms를 유지한다. 시작·착지180ms 동안 이동/방향전환·공격·점프·대시를 잠근다. 공중에서는 A/D 이동·방향전환이 가능하고 상승/낙하 전용 좌우 모션을 표시한다. 착지 잠금 후 유지 키로 이동을 재개한다. 단, 점프 선입력이 유효하면 아래 웅크림 연결을 사용한다.

jump-v13-hibit-v2의 시작200ms·상승300ms·낙하600ms 반복·착지300ms 원본을 사용한다. 시험 조정으로 시작120ms·착지180ms로 재생하고 상승 재생은 기존 정점400ms에 맞춰 늘리고, 낙하는 실제 바닥 접촉까지 반복한다. 현재높이/속도로 재생 위치를 구하므로 공중 방향전환이나 대시 복귀가 모션을 처음부터 되돌리지 않는다.

시작/착지 잠금은 사용자 답변으로 확정했다. 공중 대시는 상승/낙하에서만 가능하고 기존1회/착지회복·이동200ms 체공을 유지한다. 대시 종료 후 현재 상승/낙하 모션으로 돌아온다. 대시 중 이미 착지했으면 대시를 끝내고 착지180ms를 재생한다. 공중 공격은 위 규칙을 따르며 재점프·유지 키 반복은 없다. 새 행동은 마지막1개만100ms 예약하며 실행 가능할 때 소비한다.

포커스 상실/최소화는 유지 키·미시작 요청을 지우되 시작한 점프/착지 동작은 완료한다. 무효 출력에서 신규 점프를 시작하지 않는다. 별도 플랫폼/충돌·가변 높이는 제외한다.

### 착지에서 연속 점프

유효한 점프 선입력이 있으면 착지 웅크림60~90ms(0-based6~8번)에서 시작 웅크림40ms(4번)로 연결한다. 착지 회복과 처음부터 다시 숙이는 동작을 생략하고 남은 준비80ms 후 이륙한다. 웅크림 이전 입력은100ms 유효기간 안에 연결 지점에 도달해야 한다. 웅크림을 지난 입력은 기존 착지 완료 후 시작 모션을 처음부터 재생한다. 좌우·위치·높이166·공중 제한을 유지하며 점프 입력을1회 소비하므로 Space를 계속 누르는 것만으로 반복하지 않는다. 공격/대시는 이 연결 예외를 사용하지 않는다.

## 대시

Shift(좌/우)를 새로 누르면 현재 방향으로 준비100ms → 이동200ms → 복귀167ms의 전용 모션을 재생한다. 총467ms 동안 방향 전환·공격·점프·추가 대시를 잠근다. 수평 이동은 이동200ms 구간에서만 키2배인166 월드 단위이며 준비/복귀 중에는 정지한다. 공중 대시 이동200ms 동안 높이와 수직 속도를 고정한다. 준비/복귀에서는 중력을 적용하며 복귀 시작에 보관된 수직 속도에서 이어간다. 점프 중 공중 대시1회로 체공이200ms 늘어난다. 지상·공중에서 사용하며 공중1회는 착지 시 회복한다.

진입 당시 idle/Run에 따라 준비 클립을 고른다. 이동 종료 시 같은 방향 키가 유지되고 화면 경계에 여유가 있으면 Run 복귀, 아니면 idle 복귀를 선택한다. 복귀가 시작되면 클립/방향을 고정하고 끝에서 현재 유지 키/경계에 맞춰 일반 이동으로 전환한다. 원본의 마지막 자세를 반복하지 않도록 idle 복귀→idle은1번, Run 복귀→같은 방향 Run은15번 프레임으로 이어간다. 반대 방향/다른 클립 전환은0번부터 재생한다. 일반 이동은 다음 갱신부터 시작한다.

공격 중 대시도100ms 예약하며 유지 키 반복은 없다. 동시 입력은 마지막으로 받은 행동을 사용한다. 화면 경계에 닿으면 실제 거리가 줄어든다. 포커스 상실은 유지 키·미시작 요청만 지우고 진행 중 동작은 완료하며, 무효 출력에서는 새 대시를 시작하지 않는다.

전류 효과는 이동 시작 시 해당 방향으로 이동할 여지가 있을 때만 실제 캐릭터 위치에 생성해 뒤쪽에서367ms 재생한다. 이미 막힌 방향의 대시는 효과를 만들지 않으며 모션·행동 잠금은 유지한다. 좌우 전용 시트/기준점을 사용하고 출발점과 방향을 고정한다. 원본은166 월드 단위의 직선 경로로 제작된 잔상이므로 공중 곡선·화면 경계에 맞춰 늘리거나 자르지 않는다. 독립 idle/Run 자산은 그대로 사용하며 연결용 눈 보정본으로 교체하지 않는다.

전용 모션/효과·준비/복귀 행동 잠금·거리/공중1회는 사용자 결정이다. Shift·중력 유지는 기술 기본안이다. 대시 자체의 별도 쿨다운·무적·공격 판정은 없다. 적 돌진에 의한 피격은 [기본 적 전투](basic-enemy.md)를 따른다.

우클릭은 가장 가까운 활성 전하로 자동 순간이동하며 대상이 없으면 아무 동작도 하지 않는다. 선택·선입력 규칙은 [전하 순간이동](charge-teleport.md#우클릭-자동-선택)을 따른다.
