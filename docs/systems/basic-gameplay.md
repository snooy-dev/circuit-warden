# 기본 게임플레이

상태: 2026-11-23 요청으로 이동 공격·가변 점프·플랫폼 훈련장과 수평 추적 카메라를 적용했다. 세부 수치는 플레이 조정용이다.

## 규칙과 소유 범위

- 플레이 레벨은 GameplayMode를 사용한다. 타이틀 등 다른 규칙의 레벨은 향후 별도 모드를 지정한다.
- Warden은 A/D로 수평 이동한다. 양쪽 동시 입력은 정지하고 하나를 놓으면 남은 방향으로 이동한다.
- E는 커서 위치에 기술 전하를 만든다. [생성 조건](charge-teleport.md#워든의-전하-생성-기술)을 적용한다.
- 첫 레벨에서는 장치 가까이에 발을 딛고 W를 누른다. 배전실 릴레이는 버스바 방전을 멈추고 귀환교와 출력 셔터를 연다. 갤러리 아래 점검대의 W는 덮개를 열어 이전 층으로 이어지는 지름길을 만든다. [첫 레벨 전원 구역](../game-design.md#첫-레벨-전원-구역).
- 활성 전하 왼쪽 클릭은 [순간이동](charge-teleport.md)이 우선한다. 그 외 왼쪽 클릭과 J는 지상 또는 공중 공격 1회다. J는 키 반복을 무시한다. 공격 시작 시 이동 입력 방향 또는 마지막 방향을 스윙에 고정한다. 지상·공중 모두 공격 시작부터 A/D로 이동할 수 있다. 추가 공격은 100ms 선입력으로 처리한다.
- 이동 중 Run, 정지 중 idle, 공격 중 단발 공격을 재생한다. 기본 적과 피해 판정은 [기본 적 전투](basic-enemy.md)를 따른다. 콤보는 포함하지 않는다.

전하 순간이동은 공격·점프·대시의 잠금 예외로 현재 동작과 선입력을 즉시 취소한다. 도착·낙하 규칙은 [전하 순간이동](charge-teleport.md)을 따른다.

실제 피격은 진행 중 행동과 이전 선입력을 취소한다. 짧은 반동 뒤 지상에서 일반 조작으로, 공중에서 상승·낙하 조작으로 돌아온다. 피격 중 누른 새 공격과 대시는 150ms를 보관한다. 유효 전하는 즉시 사용할 수 있다. [기본 적 전투](basic-enemy.md).

## 상태 전이·경계 조건

idle ↔ run은 실제 이동 여부로 결정한다. idle/run → attack은 왼쪽 클릭 또는 J로 실행한다. 지상 공격은 준비·타격·회복 내내 A/D 이동을 적용한다. 모션이 끝나면 현재 이동 입력에 따라 Run 또는 idle로 이어진다.
포커스 상실·최소화는 유지 키와 미시작 공격을 지운다. 시작한 공격은 계속 끝낸다. 무효 출력에서는 새 공격을 시작하지 않는다. 창 크기는 카메라 시야를 바꾸며 레벨 내 이동 경계는 지형이 결정한다.

## 기술 가정·검증

속도·배율·바닥선·경계는 [기술 구조](../architecture.md)를 따른다. 지상 340ms, 공중 300ms 원본을 80% 재생률로 진행한다. 재생 시간은 지상 425ms, 공중 375ms이며 착지로 공중 공격이 먼저 끝날 수 있다. 왼쪽 베기는 수평 반전한다. 캐릭터와 효과 출처는 [아트 기준](../art-direction.md#게임에서-사용하는-캐릭터-자산)을 따른다. [검증 기록](../../specs/030-responsive-combat/verification.md).

지상 베기의 분기 방전 초승달은 125ms에 시작해 175ms에 최대 높이 98월드 단위로 펼쳐지고 275ms에 사라진다. 공중 베기는 약 146ms부터 보이며 최대 높이는 100월드 단위다. 공격이 취소되면 효과도 함께 끝난다. 접촉과 적중 효과는 [기본 적 전투](basic-enemy.md)가 소유한다.

### 공중 공격

상승·낙하 중에는 J 또는 전하를 선택하지 않은 왼쪽 클릭으로 공격한다. 점프 시작·대시 중에는 공격을 잠그며, 마지막 행동 1개를 기억한다. 공격 입력은 기본 100ms 동안 유효하다. 전하 클릭이 우선한다. 공중 공격 중 A/D와 중력·현재 점프 속도를 계속 적용하며, Space를 떼면 사용자 점프의 상승을 줄인다.

공격이 끝났을 때 공중이면 실제 상승·낙하 단계의 점프 모션으로 돌아간다. 공중에서 시작한 공격 도중 지형에 착지하면 남은 타격과 모션을 끝내고 일반 착지로 전환한다. 착지는 공중 대시를 복구한다. 피해·활성 시간·공격당 1회 규칙은 [기본 적 전투](basic-enemy.md)를 따른다.

### 공중 아래 베기

공중에서 S를 누른 채 J 또는 전하를 선택하지 않은 왼쪽 클릭을 누르면 아래를 벤다. 65ms 준비와 90ms 타격 구간을 거쳐 총 245ms 동안 발밑으로 전기 궤적을 표시한다. A/D 조향과 중력은 계속 적용한다.

지형에 가려지지 않은 아래쪽 적을 먼저 맞히면 타격 정지 동안 베기 자세를 유지한다. 이후 위로 튀고 공중 대시 1회를 회복한다. 헛치면 낙하를 이어가며 지형에 먼저 착지하거나 피격·순간이동하면 아래 베기를 종료한다. 지속 시간과 반동 높이는 시험값이다. [검증 기록](../../specs/032-downstrike/verification.md).

## 점프

평지에서 Space를 새로 누르면 짧은 준비 후 이륙한다. 이륙 전 키를 놓아도 짧은 점프가 나가며, 상승 중에는 Space를 늦게 뗄수록 높이와 체공 시간이 늘어난다. A/D를 유지하면 긴 점프에서 더 멀리 간다. 준비 중에는 이동·방향전환·공격·대시를 잠근다. 착지 후 입력이 중립이면 최대 180ms 착지 모션을 재생한다. 방향 입력·공격·대시는 일반 착지 모션을 끊고 각각의 조작으로 이어진다. 공중에서는 A/D 조작과 상승·낙하 전용 모션을 적용한다. [점프 수치](../architecture.md#warden-점프).

jump-v13-hibit-v2의 시작·상승·낙하·착지 원본을 사용한다. 상승과 낙하는 수직 속도로 재생 위치를 구하므로 공중 방향전환이나 대시 복귀가 모션을 처음부터 되돌리지 않는다.

공중 대시는 상승/낙하에서만 가능하고 공중 1회, 착지 시 회복, 이동 200ms 체공을 적용한다. 대시 종료 후 현재 상승/낙하 모션으로 돌아온다. 대시 중 이미 착지했으면 대시 종료 후 착지 모션 또는 아래 연속 점프 규칙을 적용한다. 새 행동은 마지막 1개만 보관하고 실행할 때 한 번 소비한다. 공격·대시와 지상에서 잠긴 점프 입력은 100ms 동안 유효하다.

포커스 상실·최소화는 유지 키와 미시작 요청을 지우고 직접 시작한 상승에는 키 해제를 적용한다. 순간이동 상승과 피격 반동은 각 시스템이 준 속도를 따른다. 발판 가장자리에서 내려가면 낙하로 이어진다.

### 발판 끝에서 점프

일반 좌우 이동으로 발판을 벗어난 뒤 80ms 미만에 새로 Space를 누르면 떨어지던 위치에서 바로 상승한다. Space를 빨리 떼면 짧게 뛴다. 유예는 한 번만 쓸 수 있으며 대시·적의 밀침·피격 반동·순간이동으로는 얻을 수 없다. 유예가 지나면 아래 착지 선입력 규칙을 따른다. 80ms는 조작감 확인을 위한 시험값이다.

### 착지에서 연속 점프

공중에서 새 Space 입력은 120ms 동안 유효하다. 평지나 발판에 닿는 순간 유효한 점프 입력이 있으면 바로 재이륙한다. 기본 착지 180ms 중 새로 Space를 눌러도 즉시 다시 뛴다. 재이륙은 상승 모션부터 재생하고, Space를 미리 뗐으면 짧게 뛴다. 키를 계속 누르면 한 번만 뛰며, 대시·피격 잠금은 끝날 때까지 적용한다. 120ms는 조작감 확인을 위한 시험값이다.

## 플랫폼 훈련장

`main.py --training`으로 바닥, 양끝 벽, 중간 낮은 벽, 두 높이의 공중 발판 여섯 개가 있는 훈련장을 연다. 공중 발판 밑면은 바닥에서 최소 104px 높이다. 발판 아래를 달리고, 옆에서 뛰어오르고, 가장자리에서 내려올 수 있다. 좌우 이동 시 카메라는 실제 워든 위치를 약간 늦게 따라간다. 지형에 닿아 같은 방향으로 이동할 수 없으면 화면 이동을 멈춘다. `R`은 워든과 카메라를 시작 위치로 돌린다.

## 대시

Shift(좌/우)를 새로 누르면 시작 시점의 A/D 방향으로 준비100ms → 이동200ms → 복귀167ms의 전용 모션을 재생한다. 좌우 입력이 중립이면 보던 방향을 사용한다. 총467ms 동안 방향 전환·공격·점프·추가 대시를 잠근다. 수평 이동은 이동200ms 구간에서만 키2배인166 월드 단위이며 준비/복귀 중에는 정지한다. 공중 대시 이동200ms 동안 높이와 수직 속도를 고정한다. 준비/복귀에서는 중력을 적용하며 복귀 시작에 보관된 수직 속도에서 이어간다. 점프 중 공중 대시1회로 체공이200ms 늘어난다. 지상·공중에서 사용하며 공중1회는 착지 시 회복한다.

진입 당시 idle/Run에 따라 준비 클립을 고른다. 이동 종료 시 같은 방향 키가 유지되고 길이 열려 있으면 Run 복귀, 아니면 idle 복귀를 선택한다. 복귀 방향과 클립을 고정하고 끝에서 현재 입력과 지형에 맞춰 일반 이동으로 전환한다. idle 복귀→idle은1번, Run 복귀→같은 방향 Run은15번 프레임으로 이어간다. 반대 방향과 다른 클립은0번부터 재생한다. 일반 이동은 다음 갱신부터 시작한다.

공격 중 대시는 100ms 예약한다. 검격 유효 구간이 끝나는 원본 200ms 지점(80% 재생률에서 250ms)부터 남은 공격 복귀 모션을 대시 준비로 전환할 수 있다. 이미 발생한 타격과 밀림·공중 대시 제한을 적용하며 유지 키 반복은 적용하지 않는다. 동시 입력은 마지막으로 받은 행동을 사용한다. 벽에 닿으면 실제 대시 거리가 줄어든다. 포커스 상실은 유지 키와 미시작 요청을 지우고 진행 중 동작은 완료한다. 무효 출력에서는 새 대시를 시작하지 않는다.

전류 효과는 이동 시작 시 해당 방향으로 이동할 여지가 있을 때만 실제 캐릭터 위치에 생성해 뒤쪽에서367ms 재생한다. 이미 막힌 방향의 대시는 효과를 만들지 않으며 모션·행동 잠금은 유지한다. 좌우 전용 시트/기준점을 사용하고 출발점과 방향을 고정한다. 원본은166 월드 단위의 직선 경로로 제작된 잔상이므로 공중 곡선·화면 경계에 맞춰 늘리거나 자르지 않는다. 독립 idle/Run 자산은 그대로 사용하며 연결용 눈 보정본으로 교체하지 않는다.

전용 모션/효과·준비/복귀 행동 잠금·거리/공중1회는 사용자 결정이다. Shift·중력 유지는 기술 기본안이다. 대시 자체의 별도 쿨다운·무적·공격 판정은 없다. 적 돌진에 의한 피격은 [기본 적 전투](basic-enemy.md)를 따른다.

우클릭은 가장 가까운 활성 전하로 자동 순간이동하며 대상이 없으면 아무 동작도 하지 않는다. 선택·선입력 규칙은 [전하 순간이동](charge-teleport.md#우클릭-자동-선택)을 따른다.
