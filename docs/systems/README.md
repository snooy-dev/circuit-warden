# 시스템 설계

- [기본 게임플레이](basic-gameplay.md): 플레이 모드, A/D 이동, 클릭 단발 공격과 상태 전이. 초기 구현·검증 완료.
- [전하 순간이동](charge-teleport.md): 가까운 전하 활성화·클릭 순간이동. 핵심 메커니즘으로 확정했으며 미구현.

- [기본 적 전투](basic-enemy.md)는 현재 플레이 레벨의 금속 먼지 덩어리와 양방향 피해를 다룬다.

각 문서는 목적·승인 상태·규칙과 수치의 소유 범위·상태 전이·관계·경계 조건·검증 기준을 포함한다. 다른 문서의 수치는 참조한다.
