# 전하 순간이동

상태: 워든 기술과 환경이 전하를 생성한다. 이동에 성공하면 두 종류 모두 소모된다. [검증](../../specs/018-charge-generation/verification.md).

## 목적과 소유 범위

전하 활성화·선택·순간이동 규칙을 소유한다. 목표는 접근 → 공격 → 재배치다. [게임 설계](../game-design.md), [기본 조작](basic-gameplay.md), [012 명세](../../specs/012-charge-teleport/spec.md)를 참조한다.

## 확정 규칙

- 레벨에 떠 있는 전하는 워든이 가까워지면 활성화된다. 실제 이동에 성공하면 도착 전하는 사라진다. R로 전투를 재시작하면 기술 전하가 정리되고 환경 전하가 새로 배치된다.
- 전하 표시보다 넓은 원형 클릭 판정으로 선택을 돕는다. 활성 전하 판정 안을 왼쪽 클릭하면 공격보다 먼저 순간이동한다. 소모·비활성 전하 또는 판정 밖 클릭은 기존 공격 입력으로 전달한다.
- 공격·점프 준비/상승/낙하/착지·대시 중에도 현재 행동을 즉시 끊고 이동한다. 같은 클릭으로 공격하지 않는다.
- 출발점과 도착점을 연결하는 전류는 피해 없는 시각 효과다. 후속 사용자 지시로 짧고 순간적으로 나타나게 재생 시간을 압축한다.
- 순간이동 진행 중 다른 순간이동을 시작할 수 없다. 목표 지점을 기준으로 주변 전하를 즉시 활성화하고 선입력으로 다음 이동을 이어간다.
- 정확한 활성화 거리는 실제 플레이로 확정한다.
- 첫 레벨의 닫힌 전력 셔터에 몸통 경로가 닿는 순간이동은 시도할 수 없다.

## 이번 구현의 기술 시험안

- 활성 거리 300 월드 단위(경계 포함), 클릭 반경 48(경계 포함, 지름96). 표시80×80은 유지하며 사용자 요청으로 클릭 판정만 확대한다. 평소에는 캐릭터 중심, 순간이동 진행 중에는 목표 지점을 기준으로 계산한다. 시작 이벤트에서 논리 활성 상태를 즉시 갱신하며 승인된 시각 전환 완료를 기다리지 않는다.
- 캐릭터 중심은 기존 발 기준점에서 키 절반 위이며 이 중심을 전하 중심에 정렬한다. 사용자 플레이 피드백으로 공중 도착에는 약한 상승 속도를 주고 기존 중력·A/D·낙하·착지로 이어간다. 시험값은240ms 동안 최대59.76월드 단위 상승,480ms 후 도착 높이 복귀다. 속도는 매번 교체해 누적하지 않으며 화면 상단 여유가 부족하면 줄인다. 여유0이면 낙하하고 바닥 도착은 기존 지상 상태를 유지한다. 순간이동 종료 후 상승·낙하 상태의 공격은 [공중 공격](basic-gameplay.md#공중-공격) 규칙을 따른다.
- 방향·유지 키·공중 대시 소모 이력은 유지하고 이전 행동의 선입력은 제거한다. 바닥 도착 때만 공중 대시를 회복한다.
- 전류 효과와 순간이동 진행 시간은100ms 시험값이다. 원본400ms의12프레임을 이 시간에 압축한다. 진행 중 유효 전하 클릭은 마지막1개만 예약하며 현재 이동을 끊거나 공격으로 전달하지 않는다. 종료와 같은 갱신에서 재검사 후1회 이동하고 예약은 비운다. 이동에 성공하면 같은 길이의 돌진 피해 보호가 시작된다. 몸통은 여전히 워든을 밀고, 적이나 지형에 겹치는 위치로는 이동할 수 없다.
- 선입력은 현재 순간이동이 끝날 때까지만 유지하며 포커스 상실·최소화·무효 출력·대상 소멸/거리/도착 경계 불충족이면 취소한다. 같은 위치를 선택하면 전하와 워든의 진행 동작을 유지한다. 실패한 예약도 전하를 소비하지 않는다.
- 전하가 겹치면 클릭 중심에서 가까운 대상, 동률이면 배치 순으로 선택한다.
- 바닥 아래나 현재 카메라 시야 밖으로 나가거나 월드 지형·적과 겹치는 도착은 선택에서 제외한다. 클릭은 현재 카메라와 출력 배율을 써서 월드 좌표로 변환한다. 무효 출력에서는 이동하지 않는다.

## 워든의 전하 생성 기술

- 창 안의 커서 위치를 가리키고 E를 누르면 기술 전하를 만든다. 지상·공중에서 현재 행동을 이어가며 생성할 수 있다.
- 거리 기준은 기존 활성 거리의 기준점이다. 생성 위치는 기준점에서 최소 클릭 반경만큼 떨어져야 하며 활성 거리 안이어야 한다. 다른 미소모 전하와 클릭 반경만큼 떨어지고 기존 순간이동 도착 조건을 충족해야 한다.
- 동시 기술 전하는 한 개다. 성공한 생성부터 0.8초 뒤에 다시 사용할 수 있고 기존 기술 전하가 사라져야 한다. 실패한 생성은 대기 시간을 시작하지 않는다. 이동하면 즉시 소멸하고 R은 기술 전하와 대기를 초기화한다.

## 환경 전하

- 시험 장면에는 다섯 구역이 있다. 각 구역은 후보 세 곳 중 한 곳에 전하 한 개를 만든다. 오른쪽의 낮은 구역과 오른쪽 위 구역은 공중 타격의 진입과 이탈에 닿는 범위를 유지한다.
- 환경 전하를 사용하면 2.5초 뒤 같은 구역의 다른 후보에 새 전하가 생성된다. 카메라 시야 밖에서도 월드 기준으로 재생성한다. 후보가 적·지형에 겹치거나 다른 전하와 클릭 반경보다 가까우면 유효한 위치가 생길 때까지 기다린다.
- R을 누르면 이전 위치와 다른 후보로 각 구역을 다시 배치한다. 생성 구역과 대기 시간은 시험값이다.

## 아트와 검증

전하 상태 v5와 전환 v2의 3초 공유 위상·중간 반전 속도·premultiplied 보간을 유지한다. 전류는 끝점을 고정하고 임의 거리·방향에서 중심 굵기를 늘리지 않는다. 현재 전류가 종료돼야 다음 순간이동을 시작하므로 플레이어의 연결 효과는 겹치지 않는다. A/D·점프·대시·빈 곳 공격 규칙은 유지한다.

소모한 전하는 즉시 선택과 표시에서 빠진다. 도착점에는 연결 효과와 같은 시간 동안 축소하는 전류가 보인다. [효과 미리보기](../../assets/combat/source/preview.png).

출발 전류는 직전 화면의 워든 몸 중심에서 시작하고, 도착 전류는 전하 중심에 고정된다. 첫 화면의 워든도 도착점에 놓고 45ms 동안 실제 위치로 이어준다. 지상 도착은 짧은 착지 자세를 쓰고 공중 도착은 실제 상승 시작 속도에 맞춰 첫 상승 자세부터 재생한다. 보간은 표시용이며 이동·입력·판정 시간에는 영향을 주지 않는다.

거리 경계·입력 우선순위·상태 취소·선입력·창 좌표와 두 생성원의 자원 수명을 표적 검사한다. 실제 창에서는 생성·소멸·재생성과 공중 전투를 관찰한다. [검증](../../specs/018-charge-generation/verification.md).

## 미확인 사항

활성 거리·클릭 판정·배치·100ms 진행 시간·일회성 소비·상승 관성의 최종 조작감은 사용자 재확인 전이다. 넓어진 판정에서 공격하려던 클릭이 인접 전하를 선택하는 빈도도 확인한다. 장애물 통과 규칙은 후속 설계 범위다.

## 우클릭 자동 선택

우클릭은 커서 위치와 무관하게 활성 기준점에서 가장 가까운 유효 전하를 자동 선택한다. 평소 기준점은 캐릭터 중심, 순간이동 진행 중에는 도착점이다. 동률은 배치 순이며 두 입력 모두 소비한 전하를 제외한다. 대상이 없으면 공격·이동 없이 기존 상태/예약을 유지하고, 무효 출력에서는 실행하지 않는다. 선택 후 취소·상승·진행 중 마지막 유효 선입력·완료 시 재검사는 왼쪽 클릭과 공유한다. 우클릭을 누른 시점에 대상 하나를 고르며 유지한 채 자동 반복하지 않는다.
