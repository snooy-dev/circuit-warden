# 전하 순간이동

상태: 2026-11-15 사용자 구현 요청 범위의 구현·표적/실제 SDL 검증 완료. 왼쪽 클릭 우선·모든 행동 즉시 취소는 후속 답변으로 확정했다.

## 목적과 소유 범위

전하 활성화·선택·순간이동 규칙을 소유한다. 목표는 접근 → 공격 → 재배치다. [게임 설계](../game-design.md), [기본 조작](basic-gameplay.md), [012 명세](../../specs/012-charge-teleport/spec.md)를 참조한다.

## 확정 규칙

- 레벨에는 떠 있는 원형 전하가 있으며 캐릭터가 가까우면 활성화된다. 공격·접촉·스위치 조건은 없다.
- 전하 표시보다 넓은 원형 클릭 판정으로 선택을 돕는다. 활성 전하 판정 안을 왼쪽 클릭하면 공격보다 먼저 순간이동한다. 비활성 전하·판정 밖 클릭은 기존 공격 입력으로 전달한다.
- 공격·점프 준비/상승/낙하/착지·대시 중에도 현재 행동을 즉시 끊고 이동한다. 같은 클릭으로 공격하지 않는다.
- 출발점과 도착점을 연결하는 전류는 피해 없는 시각 효과다. 후속 사용자 지시로 짧고 순간적으로 나타나게 재생 시간을 압축한다.
- 순간이동 진행 중 다른 순간이동을 시작할 수 없다. 목표 지점을 기준으로 주변 전하를 즉시 활성화하고 선입력으로 다음 이동을 이어간다.
- 정확한 활성화 거리는 실제 플레이로 확정한다.

## 이번 구현의 기술 시험안

- 활성 거리 300 월드 단위(경계 포함), 클릭 반경 48(경계 포함, 지름96). 표시80×80은 유지하며 사용자 요청으로 클릭 판정만 확대한다. 평소에는 캐릭터 중심, 순간이동 진행 중에는 목표 지점을 기준으로 계산한다. 시작 이벤트에서 논리 활성 상태를 즉시 갱신하며 승인된 시각 전환 완료를 기다리지 않는다.
- 캐릭터 중심은 기존 발 기준점에서 키 절반 위이며 이 중심을 전하 중심에 정렬한다. 사용자 플레이 피드백으로 공중 도착에는 약한 상승 속도를 주고 기존 중력·A/D·낙하·착지로 이어간다. 시험값은240ms 동안 최대59.76월드 단위 상승,480ms 후 도착 높이 복귀다. 속도는 매번 교체해 누적하지 않으며 화면 상단 여유가 부족하면 줄인다. 여유0이면 낙하하고 바닥 도착은 기존 지상 상태를 유지한다. 기존 공중 공격 제외를 유지한다.
- 방향·유지 키·공중 대시 소모 이력은 유지하고 이전 행동 요청과 100ms 선입력은 제거한다. 바닥 도착 때만 공중 대시를 회복한다.
- 전류 효과와 순간이동 진행 시간은100ms 시험값이다. 원본400ms의12프레임을 이 시간에 압축한다. 진행 중 유효 전하 클릭은 마지막1개만 예약하며 현재 이동을 끊거나 공격으로 전달하지 않는다. 종료와 같은 갱신에서 재검사 후1회 이동하고 예약은 비운다. 별도 추가 쿨다운·소모는 없다.
- 선입력은 현재 순간이동이 끝날 때까지만 유지하며 포커스 상실·최소화·무효 출력·대상 소멸/거리/도착 경계 불충족이면 취소한다. 종료 후 같은 위치 클릭은 소비하되 이동·새 효과를 만들지 않는다.
- 전하가 겹치면 클릭 중심에서 가까운 대상, 동률이면 배치 순으로 선택한다.
- 캐릭터가 바닥 아래나 화면 밖으로 나가는 도착은 선택에서 제외한다. 창 크기·출력 배율에 맞춰 클릭 좌표를 변환하고 무효 출력에서는 이동하지 않는다.
- 배치 5개는 현재 단일 시험 장면용이다. 장애물·적·무적·피해 시스템은 추가하지 않는다.

## 아트와 검증

전하 상태 v5와 전환 v2의 3초 공유 위상·중간 반전 속도·premultiplied 보간을 유지한다. 전류는 끝점을 고정하고 임의 거리·방향에서 중심 굵기를 늘리지 않는다. 현재 전류가 종료돼야 다음 순간이동을 시작하므로 플레이어의 연결 효과는 겹치지 않는다. A/D·점프·대시·빈 곳 공격 규칙은 유지한다.

거리 경계·입력 우선순위·상태 취소·선입력 제거·낙하·공중 대시 이력·창 좌표·자원 수명을 표적 검사한다. 실제 창에서는 상태 식별·연결·전환을 관찰한다. 실행 결과는 [검증](../../specs/012-charge-teleport/verification.md)에 기록한다.

## 미확인 사항

활성 거리·클릭 판정·배치·100ms 진행 시간·무소모 재사용·상승 관성의 최종 조작감은 사용자 재확인 전이다. 넓어진 판정에서 공격하려던 클릭이 인접 전하를 선택하는 빈도도 확인한다. 공중 공격·장애물 통과/피해 시스템과의 결합은 후속 설계 범위다.

## 우클릭 자동 선택

우클릭은 커서 위치와 무관하게 활성 기준점에서 가장 가까운 유효 전하를 자동 선택한다. 평소 기준점은 캐릭터 중심, 순간이동 진행 중에는 도착점이다. 동률은 배치 순이며 좌클릭·우클릭으로 마지막 도착한 전하 객체는 우클릭 후보에서 제외한다. 공중에서는 다음 전하 도착 성공 시 제외 대상을 교체하고, 착지 즉시(착지 모션 종료 전) 또는 지상 도착·장면 종료 시 비운다. 좌클릭 직접 선택은 제외하지 않는다. 대상이 없으면 공격·이동 없이 기존 상태/예약을 유지하고, 무효 출력에서는 실행하지 않는다. 선택 후 취소·상승·진행 중 마지막 유효 선입력·완료 시 재검사는 왼쪽 클릭과 공유한다. 우클릭을 누른 시점에 대상 하나를 고르며 유지한 채 자동 반복하지 않는다.
