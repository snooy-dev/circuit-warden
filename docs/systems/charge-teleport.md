# 전하 순간이동

상태: 2026-11-15 사용자 설명과 후속 정정에 따른 핵심 규칙 확정. 기획 기록 단계이며 미구현이다.

## 목적과 소유 범위

전하의 활성화·선택·순간이동 규칙을 소유한다. 게임의 정체성과 목표 전투 경험은 [게임 설계](../game-design.md), 기존 이동·공격·점프·대시는 [기본 게임플레이](basic-gameplay.md)를 따른다.

## 확정 규칙

- 레벨에는 떠 있는 원형 전하 객체가 있다.
- 플레이어가 가까워지면 전하가 활성화된다. 활성화는 거리 조건이며 별도의 공격·접촉·스위치 조건을 요구하지 않는다.
- 활성화된 전하를 마우스로 클릭하면 플레이어 캐릭터가 해당 전하 위치로 순간이동한다. 비활성 전하는 순간이동 대상으로 클릭할 수 없다.
- 순간이동하면 출발점과 도착점을 연결하는 전기 이펙트가 나타난다.
- 정확한 활성화 거리는 실제 플레이로 확정한다. 이 문서에서 임의의 수치를 정하지 않는다.

## 기존 행동과의 관계·미정 사항

- 사용할 마우스 버튼과 공격 입력과의 우선순위는 미정이다. 현재 왼쪽 클릭 공격 규칙을 이번 기획 기록만으로 바꾸지 않는다.
- 현재 공중 공격은 제외돼 있다. 떠 있는 전하로 이동한 뒤 공격하는 경험을 위해 도착 높이·낙하와 공중 공격의 관계를 정해야 한다.
- 공격·점프·대시 도중 순간이동 가능 여부, 순간이동 직후 행동 가능 시점은 미정이다.
- 사용한 전하의 유지·소모·재사용, 쿨다운·무적·장애물 통과 여부는 정하지 않았다.
- 연결 전기 이펙트의 지속 시간·구체적인 형태는 미정이다. 이펙트에 피해 판정이 있는지는 정하지 않았다.
- 거리 판정 기준점·경계 처리, 도착 시 캐릭터 기준점과 전하 위치의 정렬, 전하가 겹칠 때 선택 규칙은 구현 계획에서 다룬다.

## 검증 기준

구현 시 가까운 전하의 활성화와 먼 전하의 선택 불가, 활성 전하 클릭 후 해당 위치 이동을 확인한다. 순간이동 시 전기 이펙트가 해당 이동의 출발점과 도착점을 연결하는지 확인한다. 활성화 거리의 최종 수치와 접근 → 공격 → 재배치의 속도감은 실제 플레이로 판단한다. 조준 난도·활성 상태의 식별·행동 전환의 지연이 흐름을 끊는지 함께 확인한다.

현재는 문서 내용·링크·공백만 확인하며 게임 동작 검증은 수행하지 않는다.
