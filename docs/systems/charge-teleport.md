# 전하 순간이동

상태: 2026-11-15 사용자 구현 요청으로 개발 중. 왼쪽 클릭 우선·모든 행동 즉시 취소는 후속 답변으로 확정했다.

## 목적과 소유 범위

전하 활성화·선택·순간이동 규칙을 소유한다. 목표는 접근 → 공격 → 재배치다. [게임 설계](../game-design.md), [기본 조작](basic-gameplay.md), [012 명세](../../specs/012-charge-teleport/spec.md)를 참조한다.

## 확정 규칙

- 레벨에는 떠 있는 원형 전하가 있으며 캐릭터가 가까우면 활성화된다. 공격·접촉·스위치 조건은 없다.
- 활성 전하를 왼쪽 클릭하면 공격보다 먼저 순간이동한다. 비활성 전하·빈 곳 클릭은 기존 공격 입력으로 전달한다.
- 공격·점프 준비/상승/낙하/착지·대시 중에도 현재 행동을 즉시 끊고 이동한다. 같은 클릭으로 공격하지 않는다.
- 출발점과 도착점을 연결하는 전류는 피해 없는 시각 효과다. 승인 v4의 지속 시간은 400ms다.
- 정확한 활성화 거리는 실제 플레이로 확정한다.

## 이번 구현의 기술 시험안

- 활성 거리 300 월드 단위(경계 포함), 클릭 반경 24. 중심 기준 거리를 클릭 시 다시 계산하며 시각 전환 완료를 기다리지 않는다.
- 캐릭터 중심은 기존 발 기준점에서 키 절반 위이며 이 중심을 전하 중심에 정렬한다. 도착 시 수직 속도 0, 공중에서는 즉시 낙하 모션·중력·A/D 조작으로 이어진다. 기존 공중 공격 제외를 유지한다.
- 방향·유지 키·공중 대시 소모 이력은 유지하고 이전 행동 요청과 100ms 선입력은 제거한다. 바닥 도착 때만 공중 대시를 회복한다.
- 전하는 소모·쿨다운 없이 재사용한다. 동일 위치 클릭은 소비하되 이동·새 효과를 만들지 않는다.
- 전하가 겹치면 클릭 중심에서 가까운 대상, 동률이면 배치 순으로 선택한다.
- 캐릭터가 바닥 아래나 화면 밖으로 나가는 도착은 선택에서 제외한다. 창 크기·출력 배율에 맞춰 클릭 좌표를 변환하고 무효 출력에서는 이동하지 않는다.
- 배치 5개는 현재 단일 시험 장면용이다. 장애물·적·무적·피해 시스템은 추가하지 않는다.

## 아트와 검증

전하 상태 v5와 전환 v2의 3초 공유 위상·중간 반전 속도·premultiplied 보간을 유지한다. 전류는 끝점을 고정하고 임의 거리·방향에서 중심 굵기를 늘리지 않는다. 연속 이동의 효과는 독립적으로 소멸한다.

거리 경계·입력 우선순위·상태 취소·선입력 제거·낙하·공중 대시 이력·창 좌표·자원 수명을 표적 검사한다. 실제 창에서는 상태 식별·연결·전환을 관찰한다. 실행 결과는 [검증](../../specs/012-charge-teleport/verification.md)에 기록한다.

## 미확인 사항

활성 거리·배치·무소모 재사용·낙하 방식의 최종 조작감은 사용자 플레이 전이다. 공중 공격·장애물 통과/피해 시스템과의 결합은 후속 설계 범위다.
