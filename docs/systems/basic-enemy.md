# 기본 적 전투

구현과 표적 자동·SDL 검증을 완료했다. 사용자 직접 조작감·밸런스 평가는 미확인이다. 사용자는 GameDesign 19번 슬라이드의 적 원화로 기본 적 한 종류를 만들고, hibit 표현과 기존 피해·체력 규칙을 적용해 게임에서 실제로 싸울 수 있게 요청했다.

## 금속 먼지 덩어리

- 현재 플레이 레벨에 한 마리를 배치한다. [원화](../../art/enemies/reference/metal-dust-concept.png)를 바탕으로 만든 hibit 이미지 한 장을 사용한다. 좌우 방향과 예고·회복을 같은 이미지로 표시한다.
- 초기 적 체력은 3이다. 피해를 받으면 0.18초간 피격 반응을 표시한다. 체력이 0이면 적과 체력 표시가 사라지고 적 행동이 끝난다.
- 적은 대기, 접근, 공격 예고, 돌진, 회복 순서로 행동한다. 예고가 시작되면 돌진 방향이 고정된다. 피해는 돌진 중 접촉할 때 한 번만 적용하며 점프로 판정 범위를 벗어날 수 있다.

### 시험 동작 수치

다음 값은 플레이 조정용 기술 기본값이다. 초기 위치는 워든보다 오른쪽220, 대기0.18초, 접근속도100 월드 단위/초, 예고거리72, 예고0.45초, 돌진속도350 월드 단위/초·지속0.28초, 회복0.60초다. 적의 몸통 판정은 중심 좌우30·발부터 높이55이며 워든은 중심 좌우24·발부터 기존 몸 높이다. 예고·돌진·회복의 외형 축소는 판정 상자의 크기를 바꾸지 않는다.

## 피해와 재시작

- 워든의 기본 입력과 행동은 [기본 게임플레이](basic-gameplay.md)를 따른다. 검 공격은 경과 0.10초부터 0.20초 미만에만 전방 85와 발 기준 높이 8~70 월드 단위에서 맞는다. 유효 타격 한 번당 피해 1이며 같은 공격은 한 번만 맞힌다. 이 판정과 적 체력은 `feature/training-combat`의 `e343742`·`ebcad98`에서 가져왔다.
- 워든은 초기 체력 5이며 돌진 피격당 피해 1을 받는다. 피격 보호는 실제 접촉 시점부터 0.75초이며 대시는 자체 무적이 없다. 보호 중에 첫 접촉한 돌진은 피해 없이 소비하므로 같은 돌진이 겹친 채 보호가 풀려도 다시 맞히지 않는다. 베기 이펙트는 시각 효과다.
- 워든 체력이 0이면 전투 입력과 적 행동이 멈추며 마지막 자세를 흐리게 표시한다. R을 새로 누르면 위치·체력·행동·피격 보호·공격 기록을 초기화하고 남은 베기/대시 효과를 제거한다.
- 검의 치명타와 돌진 접촉이 같은 갱신에 겹치면 검의 적 처치를 우선하며 제거된 적은 피해를 주지 않는다.
- 초기 워든 체력은 기획안의 적용값이다. 돌진의 세부 수치, 피격 보호 시간, R은 실제 플레이에 맞춰 조정 가능한 기술 기본값이다.

표적 검사와 실제 SDL 창 관찰 결과는 [검증 기록](../../specs/013-basic-enemy/verification.md)에서 확인한다.
