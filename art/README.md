# 게임 적용용 아트

워든의 최신 모션은 [게임 적용용 모션 목록](game-ready/warden/animations.json)에서 찾을 수 있다. 게임에 가져갈 단위는 `game-ready/warden/` 폴더 전체다. 이 폴더에는 워든 시트 18장과 재생 설정만 들어 있다.

| 폴더 | 동작 |
| --- | --- |
| `ground/` | 대기, 걷기, 달리기 출발, 달리기, 전력 질주 |
| `air/` | 발구름, 상승, 낙하, 착지, 지상 대시, 공중 대시 |
| `combat/` | 지상 베기, 공중 베기, 하단 베기, 피격 |
| `special/` | 반동, 대시 종료, 정면 순간이동 |

각 동작의 `sheet`는 목록 파일 기준 상대 경로다. 셀은 256×224이며 시트 왼쪽 위에서 오른쪽으로 읽고 다음 줄로 내려간다. 동작별 `columns`, 프레임별 `durationsMs`, 반복 여부 `loop`를 사용한다. 공통 피벗은 셀 왼쪽 위 기준 (128, 136)이다. 기본 방향은 오른쪽이며 정면 순간이동은 정면이다. 적용용 목록에서 대시 종료의 키는 `dash-end`다.

원화와 기사 비교 자료는 [워든 모션 검토본](warden/knight-motion/review.html)에 있다. 이전 제작본은 `warden/` 아래 기존 경로에 보관한다.
