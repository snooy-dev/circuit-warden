프레임은 좌상단부터 행 우선이다. animations.json의 기준점은 셀 좌상단 픽셀, 시간은 밀리초다. 제작용 이벤트·previewSpeed는 게임 규칙으로 가져오지 않았다.

지상 공격은 256×224·6열·17프레임·340ms, 피벗 (128,136)이다. 승인 HK v6·팔 보정 v3의 포즈를 사용하고 타격 자세를 100ms부터 보여준다. 220·240·260ms에 LTX 회복 영상의 4·9·11번 포즈를 사용하며 280ms부터 기존 idle 자세로 이어진다. 효과는 224×208·6프레임·피벗 (112,128)의 투명 시트에서 가져온다. 효과의 가로·세로를 최근접 1.2배로 키워 발 피벗을 기준으로 몸체 위에 합성한다. 효과 원본 SHA-256은 `34928a9373af654515c40c767597f81caa9212077b503a24793d45832ebbcc84`다. [효과 원본](../../art/warden/ground-crescent-discharge-refined/slash.png) · [합성 미리보기](../../art/warden/ground-crescent-discharge-refined/preview-dark-quarter.gif) · [재생 시점](../../docs/systems/basic-gameplay.md).

공중 공격은 256×224·6열·12프레임·300ms, 피벗 (128,136)이다. 몸 중심에 고정한 전신 검격 자세에 지상 검격의 pixelfx를 합성한다. 지상·공중 검격 모두 첫 자세를 클립 시간 12ms에 끝내고 준비 자세를 이어간다.

idle은 오른쪽 시트 96프레임·4초·기준점 (64,92)을 쓰고 왼쪽은 수평 반전한다. 대기 모션에서 발이 고정된 채 머리와 몸이 작게 움직인다. Run은 16프레임·480ms이며 Run v4 리그의 발 벌림과 들림, 골반을 중심으로 한 상체 기울기와 팔 스윙을 보정했다. 좌우는 정확히 반전되며 클립 경계의 프레임 0·15는 기존 자산과 RGBA 픽셀이 일치한다.

대시 캐릭터 클립은 128×104·4열이며 왼쪽 기준점은 (63,92), 오른쪽은 (64,92)이다. 준비는 6프레임·100ms, 이동은 11프레임·200ms, 회복은 10프레임·167ms이다. 이동 클립의 `frameIndices`는 원본 재생 순서대로 시트의 6번 셀을 건너뛴다. 셀 번호는 0부터 시작한다.

대시 효과는 384×128·6열·22프레임·367ms이며 왼쪽 기준점은 (287,112), 오른쪽은 (96,112)이다.
